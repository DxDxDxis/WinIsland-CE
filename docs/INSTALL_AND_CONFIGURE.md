# 安装、运行、配置与回退

## 选择版本

[版本索引](VERSIONS.md) 从新到旧排列。想直接使用请选择成品 `dist` 或 GitHub Releases 附件；想开发请选择该版本 `project`。alpha/beta 是预发布标识，不承诺适用于全部设备。原始源码目录名不是唯一身份证据，优先核对代码常量、原 manifest、成品哈希和该版 README。

## 当前 1.3.1alpha

1. 将主 EXE 放在你希望的位置。完整本地归档中的路径是 `versions/Winlsland-1.3.1alpha/dist/WinIsland-1.3.1alpha.exe`。
2. 双击主 EXE，首次启动按现有引导确认安装/数据根目录。优先建议 `D:\WinIsland`；D 盘不可用时会根据当前磁盘条件使用实际建议路径，允许用户修改。
3. 让程序完成依赖释放。EXE 内含 Electron 设置程序、歌词辅助依赖等，体积大于早期纯原生单文件是发行方式差异，不表示这些字节全部是业务源码。
4. 从托盘或已有设置入口进入设置。不要直接运行 `dist/settings/WinIslandSettings.exe`，它需要宿主提供 IPC 参数。
5. 后续移动 EXE 不应另建一套数据：程序通过定位记录查找已确认的根目录。目标盘不可用时恢复该盘或按提示重新选择，不删除现有数据。

建议使用受支持的 Windows 10/11 x64。常规运行无需 MSVC、Node.js 或 Python 开发环境。安全软件的具体行为与系统策略相关，本归档不要求关闭系统防护。

## 历史版本

- 早期 C# / WPF 版本依赖 Windows 中可用的 .NET Framework 4.x 组件，查看原版运行要求。
- 较早的 C++ 多文件版本需要相邻 `lyric-provider` 及 DLL，必须保留目录结构。
- 有些独立修订目录只剩 EXE，运行依赖不完整；该状态保留在版本 README，不从相邻版本静默补配依赖。
- 不要同时运行多个版本来验证同一份日常数据。回退前保存配置、插件包与中转数据副本。

## 当前设置分类

| 分类 | 常用项目 | 配置说明 |
|---|---|---|
| 界面通知 | 常驻、隐藏 Windows 横幅、显示消息、停驻时间、帧率 | 隐藏原生通知与允许岛内消息独立 |
| 音乐歌词 | 歌曲来源、播放器、歌词来源/API、显示音乐 | 开关不控制外部播放器是否播放 |
| 实时信息 | FPS、Ping、Ping 目标 | 无有效数据应显示不可用，而非伪造数值 |
| 运行诊断 | 监测、停止监测、导出报告 | 提交报告前检查个人信息 |
| 其他设置 | 缩放、宽高倍率、DPI 修正、显示器、贴顶、圆角、降低动画 | “降低动画”默认 false，持久保存用户选择 |

`settings.write` 带 revision，核心验证并原子写入成功后返回真实状态，界面据此确认开关；失败会恢复核心值。不要直接修改 IPC 协议去绕过校验。

## 插件

其他设置 → 插件管理 → 添加 `.wimod`。在同一张卡片展开详情、查看真实状态、依赖、日志与注册的设置。没有注册配置的模组不会因此自动拥有设置页。启用/禁用按稳定插件 ID 保存；不因扫描插件包就无条件执行所有插件。

插件包、SDK、宿主 ABI 分别有版本。产品版本升高不代表插件 ABI 必然改变。最新归档保留生命周期 ABI `0x00010002`；其他接口以该版本 SDK 头文件为准。

## 文件中转

其他设置 → 文件中转 → 启用文件中转。默认关闭主岛接收。

| 选项 | 实际行为 |
|---|---|
| 仅中转 | 记录来源路径及元数据，不移动、不复制原文件；源文件失效则记录失效 |
| 保存并中转 | 将副本复制到统一数据根，成功完成后标为已保存；原文件保留 |
| 从中转站移除 | 移除条目，不删除用户原文件 |
| 打开原位置 / 保存位置 | 定位实际来源或副本；失效时显示原因 |
| 侧边吸附后自动展开 | 独立偏好，默认关闭；普通点击展开不受影响 |

文件条目在自身内部展开详情，当前版没有图片/文本内容预览。支持拖出真实文件引用，目标程序可拒绝不支持的格式；不宣称所有程序都能接收。大文件复制与界面动画分离，模式确认前不会无提示复制大量文件。

## 数据目录

以下为当前系列的结构说明，确切子路径由本版代码解析：

```text
用户确认的 dataRoot/
├─ settings.xml
├─ install-state.json
├─ components/                 按运行包身份管理的组件
├─ mods/                       插件包、设置与启用选择
├─ mod-cache/                  插件解压缓存
├─ lyrics/                     歌词及相关缓存
├─ logs/                       诊断与组件日志
├─ electron-data/              设置运行时数据
├─ temp/                       应用可控制的临时文件
├─ migration/                  已知历史位置迁移记录
└─ file-transfer/
   ├─ files/                   用户明确选择保存的副本
   ├─ previews/                历史/预留缓存，当前不提供内容预览
   ├─ staging/                 未完成复制
   └─ index.*                  条目和偏好，实际文件名以源码为准
```

定位记录位于 `%LOCALAPPDATA%\WinIsland\installer\install-location.json`，只用于找到根目录。Windows 自身或第三方运行时管理的系统文件不在应用的完全控制范围内。早期版本可能直接使用 `%LOCALAPPDATA%\WinIsland`，不能套用当前规则解释所有历史成品。

## 升级和回退

停止当前实例并保存数据根目录备份；把新成品放到独立运行目录，使用已有定位记录。回退使用旧版本完整发行目录，不混合组件。不通过清空 mods 或删除 file-transfer 原文件来“修复”状态。历史版本可能不理解新配置或索引字段，先以隔离副本测试兼容性。
