## 原始数据与上传边界

本次上传没有写入 E 盘原工程。归档阶段核对了 4,732 个复制文件，合计 3,867,132,302 字节；所核对原件及副本 SHA-256 一致。范围见 `catalog/verification.json`，不把未复制缓存也说成已校验。

上传源码、SDK、资源、构建脚本、文档、图片和许可。成品单独放入 Releases。缓存、用户配置、IPC 凭据、整理草稿、下载工具及 `.publish-state` 均不上传。

同一版号只收录选定的最新构建；内部修复后缀用于来源追踪，不作为正式版本名。18 个发布标签均指向本次归档提交，不能把这些标签的 Git 日期当成原开发日期。各发行说明单独注明原 EXE 链接时间。

原始说明和源码按字节保留，其中旧开发机路径、内部后缀及缺失历史测试材料的链接可能仍存在。新版本 README 已提供有效的 GitHub 发行页入口；源码标签快照中的本地 `dist` 路径应通过对应 Release 获取。
