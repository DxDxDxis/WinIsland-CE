插件接口开放范围与限制

适用：WinIsland 1.3.1alpha 社区版，构建 1.3.1alpha-settings-adjust-20260917。源码核对日期：2026-09-17。产品版本与插件 ABI 分别管理。

结论：已经是可组合的开放场景 API，超过几个固定按钮/图层，但不是任意改写整个 WinIsland 的无边界接口。 不存在有意义且可核验的“开放百分比”；应按具体能力判断。两版 SDK 头文件相同，1.3.1alpha 新增宿主文件中转不等于新增插件接口。

实际开放的表

| 表 | 函数槽数量 | 主要能力 |
|---|---:|---|
| WinIslandHostApi | 8 | 日志、旧资源注册/删除、设置读取、动画能力/注册/控制、扩展查询 |
| WiSceneApi | 17 | snapshot/enumerate/find/read/create/clone/set/clear/remove/listen/draw/bitmap/commit/visible/onDraw/requestDraw/reset |
| WiSettingsApi | 3 | define/read/write，插件自有设置 |
| WiMediaApi | 18 | 能力、加载/查询/绑定、播放暂停停止、seek/循环/速率/音量/静音、隐藏策略、换源、数据目录来源、本地选择器 |

这是接口表规模，不是完成度或权限百分比。输入/绘制经 scene 表提供，动画经基础表提供；不存在单独的浏览器、网络、文件中转或独立窗口扩展表。

能修改什么

| 领域 | 实际支持 | 仍有边界 |
|---|---|---|
| 根岛外观与布局 | 宽高、屏幕位置、圆角、背景/透明度、可见性、边框属性；host/overlay/plugin/intrinsic 尺寸模式 | 根 SCALE/ROTATION/SHADOW 返回 UNSUPPORTED；根边框沿通用节点矩形绘制，不等于贴边外弧壳体任意重塑 |
| 组件 | Container、Text、Image、Icon、Button、Shape、Progress、Slider、Input、CustomDraw，共 10 类；创建、克隆、改父节点、移动、显隐、删除自有节点 | 这些是轻量场景图元；Input/Slider 不是全套原生富控件；无 HTML/DOM 控件 |
| 修改已有内容 | 查找已公开音乐、歌词、消息、遥测、播放按钮等节点；覆盖文字、样式、位置；可隐藏后用自有节点替换 | 只限真实导出的节点；部分宿主装饰、窗口壳与业务分支未元素化，不能宣称“所有文字按钮都任意替换” |
| 绘制 | 图形、文本、三角形、贝塞尔路径、预乘 BGRA 位图；子元素变换、裁剪、z 顺序 | 不给 HWND/D2D/D3D 裸指针；子节点实色偏移阴影可用，模糊阴影不支持；排序受父子绘制上下文约束 |
| 输入 | 左键悬停/按下/释放/点击、移动、滚轮、键盘、字符、焦点、拖动开始/更新/结束/取消；可拦截已接入播放按钮默认行为 | 不是全系统钩子；无正式全局快捷键、任意捕获请求、完整 IME/剪贴板编辑；右键等仍有宿主固定行为；没有任意 OLE 文件拖放扩展 |
| 场景读取 | 状态 flags、DPI、时间、代次、位置/尺寸、焦点、节点元数据、最近渲染的可见节点 | 不是完整 C++ 内存、通知队列、播放器控制器或插件私有状态；visible 不是逐像素遮挡计算 |
| 动画 | QuickJS-ng + GSAP 对数值属性求值，注册/开始/取消/暂停/继续/反向/取样；结果可写回场景 | 不是浏览器 JS；没有 DOM/CSS/Canvas/WebGL/fetch；onDraw 事件驱动，不保证每显示帧调用 |
| 动态媒体 | PNG/JPEG/BMP，GIF 动画，MF H.264 视频、可选音轨、播放控制/裁剪/适配 | 无网页、SVG/WebP/APNG/AVIF/WebM/HEVC/AV1/透明视频保证；当前视频软件解码，具体 capabilities 为准 |
| 插件设置 | 文本、数字范围、开关、选项，宿主插件卡片内显示并存储 | 不能注入任意设置页面 HTML；define 没有描述字段/变更订阅参数，不能虚构自动通知 |

游戏、网页、自定义工具

- 轻量小游戏：有基础，可以开发。 例如棋盘、数独、简单点击/按键互动，可组合文本/图片/绘制、输入、状态更新和设置。游戏状态/碰撞/规则需要插件实现。当前没有已交付的通用游戏引擎、专用游戏循环或稳定 60/120Hz 帧回调承诺；复杂实时游戏应先测性能。
- 嵌入可交互网页：当前正式 SDK 不支持。 没有 WebView、URL 导航、DOM、HTML/CSS 页面或浏览器输入桥。Electron 只承载宿主设置窗口，不自动成为插件网页容器。将图片绘成“网页样子”不是运行网页。
- 任意桌面小应用/独立窗口：没有正式宿主托管接口。 原生 DLL 理论上能自行链接第三方代码/Win32，但这属于绕过宿主契约，宿主不负责它创建的窗口、线程、网络、存储或卸载恢复，不能当作“SDK 已完全开放”的证据。
- 皮肤、时钟、状态仪表、交互按钮：可用现有通用接口制作。 不要求主程序为每个具体小功能新增专用 API。

生命周期与资源限制

- 正常 SDK 调用在加载器串行 worker 回调执行，错误线程/停止 owner 会失败。不要保留宿主 context 到卸载之后，也不要从自行创建的线程调用它。
- 当前最多 1024 个插件创建场景节点、32768 个暂存属性层（宿主集合上限），一次 draw 最多 4096 条指令；bitmap 最大 2048×2048、宿主累计 64 MiB。文本属性缓冲为 1024 字节含 NUL，绘制文字为 512 字节含 NUL；都按 UTF-8 字节数计。
- 媒体、脚本、包另有预算。包/单成员各 256 MiB、总展开 512 MiB，文件数最多 4096；错误文字残留“128 MiB”，实际常量是 256 MiB。不要利用文案不一致推断其他限制。
- WI_TIMER 注释约定 >=100 ms；实现按串行 worker 调度（通常等待 50 ms，有媒体时 16 ms），不是精确定时或高刷游戏时钟；WI_TASK 也在同一 worker 调度，不能拿它阻塞做后台工作。
- 修改按 owner 记录，priority 较高者优先、相同 priority 时最新 set 优先。clear/reset/禁用移除该 owner 的贡献，基于仍在运行的宿主与其他插件重算；不能保证任意插件互相覆盖没有视觉冲突。
- 原生 DLL 同进程，SEH/C++ 捕获不等于安全沙箱。输入/绘制回调超过 50 ms 在返回后记录；没有安全终止死循环或隔离任意内存破坏的保障。其他回调没有统一的可抢占超时保证。动画 JS 有独立预算，但不扩展到 DLL 全部代码。

受保护与没有导出的区域

原生/现用 Electron 设置框架和窗口创建销毁、安装目录与组件更新、加载器/签名校验/生命周期核心、托盘/开机启动/系统权限，没有正式任意修改接口。插件可以定义自己的设置项，不能据此接管整套设置程序。

1.3.1alpha 文件接收处于临时前景时，宿主决定接收尺寸/位置及输入优先级，并暂停开放场景前景绘制；保留可用宿主节点元数据。该接收状态没有新增公开 flags/事件，也没有文件中转索引、复制、独立中转组件控制 API。音乐/消息显示开关和手动 reduceMotion 是宿主设置 IPC 字段，不是 WiSettingsApi 的主程序配置读写接口。WI_REDUCED_MOTION 可供插件观察；插件动画如何响应仍要自行实现。

以上为源码核对，不新增或宣称本次实测了小游戏/网页。历史用例结果与未验证的多屏、IME、编解码边界，应继续参照对应版本验收报告。
