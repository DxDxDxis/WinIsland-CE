创建与生命周期
loader 线程先创建自己的 scene 节点，再 createView(kind,element,context,callback)。窗口、输入、OLE 和 view callback 位于宿主管理的独立 STA 线程，不能从这个线程调用旧 loader-only SDK。
CREATE 提供 parent HWND；插件可创建真正的 child HWND 并写入 nativeChild。WebView2 可直接在 parent 上建立 controller，无须返回子窗口。
布局来自同 owner 的可见场景节点；坐标由岛内 DIP 转成屏幕像素，含宿主窗口位置和岛居中偏移。LAYOUT 给物理宽高及 DPI；native child 同步尺寸。HIDDEN 要暂停自己的不可见工作。
closeView 异步关闭。DESTROY 始终通知一次，包括尚未 CREATE 就关闭、CREATE 失败；不要把 closeView 返回当成完成。关闭控制器、取消后续回调后返回。第三方异步初始化未返回时，用 manageLifetime 持续保留 DLL，直到 pending 回调为零。
每实例上限 32 个活动视图；销毁过的句柄不能再使用；关闭后条目可回收，句柄不复用。

显示与输入
NATIVE 是矩形上层窗口，不支持随意与原场景图层交错或任意透明圆角。复杂子窗口和浏览器自己的输入法/辅助功能仍由该运行库负责。
PIXELS 接收预乘 Alpha BGRA；submitFrame 同步复制调用者缓冲，返回后可释放。最大 4096x4096；stride/bytes 必须合法。按当前窗口范围裁剪，绝不拉伸旧帧冒充新尺寸。布局变化后提交新分辨率。
像素层对圆角边缘做 Alpha 覆盖采样，文本内部像素不模糊。视图本身的节点 radius/opacity 生效；不宣称原生窗口也有同样透明合成。
INPUT 借用 Windows 消息和参数，焦点有 FOCUS，IME 包含 UTF-8 合成/结果文本，flags=1 表示已提交。focusView 排队请求焦点及物理像素 caret；焦点改变仍受 Windows 前台规则控制。

GPU 共享纹理
WiSharedTexture 使用 D3D11 legacy shared HANDLE，同适配器，B8G8R8A8_UNORM，单采样/单纹理层/单 mip，SHARED_KEYEDMUTEX。
生产者 ReleaseSync(acquireKey)；宿主 AcquireSync(acquireKey,0)，忙时返回 BUSY。宿主 CopyResource 后 ReleaseSync(releaseKey)，生产者再获取 releaseKey。
HANDLE 在提交返回前保持有效；宿主只打开 COM 引用，不关闭生产者的 legacy handle。使用 PBGRA 内容。
宿主复用同尺寸 staging 纹理，Map 取得数据后复制到像素层。它能接收真实共享纹理，但不属于全 GPU 零拷贝路径。避免从 UI 回调提交需要等 GPU 的大帧，优先受管理后台任务/已登记线程。
设备 Map 失败时重置设备资源并排队 DEVICE_LOST，保留上一帧至新提交；插件重建资源。硬件不可用返回 UNSUPPORTED。

已验证：真实 HWND/EDIT 子窗口、view STA、关闭前销毁、close-before-create、D3D11 共享纹理像素/互斥键返回、WebView2 实页与反复关闭。
未验证：真实中文 IME 候选窗全流程、跨实际 DPI 显示器、所有 GPU/驱动、CEF、游戏引擎、HDR、WebView2 离屏透明合成。

STA异步回调屏障
viewBarrier在宿主视图STA回调内取得ticket，必须先取得ticket再发布pending=0/destroyed。外部lifetime.joined同时检查viewBarrierReady(ticket)==OK，表示该STA分发批次已经真正返回，覆盖回调尾声仍在执行的窗口。它不能取消未来回调；先关闭控制器、移除事件并追踪所有pending。普通外部线程仍需实际join。宿主内建lifetime不占用旧community供插件使用的16个名额。
