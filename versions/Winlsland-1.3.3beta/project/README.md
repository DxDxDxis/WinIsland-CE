# WinIsland 1.3.3beta 社区版

本目录从 **1.3.2alpha 主线**独立复制，新增文字剪贴板历史与编辑功能“复制粘贴”。主线目录只读；未使用实验分支作为实现依据。当前为 beta，验收范围与限制见 `verification/final-report.md`。

## 运行和构建

- 主程序：`build-1.3.3beta/WinIsland-1.3.3beta.exe`。
- 首次安装和数据根目录选择沿用主线；正常使用的设置、依赖和历史进入已选数据目录。
- 原生构建：在本目录执行 `./source/build.ps1 -OutputDirectory ./build-1.3.3beta`，需要 MSVC x64、Windows SDK。
- 修改设置页后先在 `settings-electron` 执行 `npm run build`、`node package.cjs`，再构建主程序，使嵌入资源与源码一致。
- 所有 `verification` 数据均为隔离测试数据，不是用户日常历史。

## 使用复制粘贴

在“其他设置”依次显示 **插件管理 / 文件中转 / 复制粘贴**。点击“复制粘贴”进入管理页，可搜索、编辑、复制、删除、批量删除、导出 TXT/MD。

系统文字剪贴板更新后，灵动岛显示“粘贴到此处”，最多展示最近四条；点击模块进入编辑。编辑支持选择、输入、滚动、Ctrl+C、Ctrl+V、Ctrl+S、右键菜单以及取消返回。“保存修改”才更新历史，“复制草稿”不会覆盖历史。“粘贴到应用”尝试恢复之前的应用焦点并发送粘贴快捷键，权限或焦点不允许时提示手动 Ctrl+V。

“显示复制粘贴提示”默认开启，仅控制提示；监听、历史落盘另有独立开关。默认保留最近 20 条，可设为 4–200，达到上限移除最旧条目。还有限制总文本量和单条大小的保护，详情见开发文档。连续相同文本合并，主动复制历史不会再创建重复记录。

## 翻译状态

已提供可替换的原生 `TranslationProvider` 接口及异步请求、取消、请求 ID、过期结果保护。**尚未接入实际在线/离线翻译后端**，生产版点击翻译会明确提示未配置，不会上传文本或伪造译文。测试用适配器不作为真实翻译能力。

## 数据与回退

历史及偏好存放在 `<dataRoot>/clipboard/history.dat`，使用当前 Windows 用户的 DPAPI 加密、原子写入。退出清空或不保存模式不把正文写入磁盘。损坏历史保留原文件并暂停捕获，需要用户明确选择备份并重置。

回退时退出本版本，运行原 `1.3.2alpha`；不要删除数据根目录、mods 或配置。旧版不读取新增 clipboard 目录。加密文件通常不能直接迁移给其他 Windows 用户，需先导出所需文本。
