WinIsland 1.3.2alpha 社区版
构建标识：1.3.2alpha-open-runtime-20260918
文档日期：2026-09-18

本版在旧 media API 下接入社区流式解码。旧 API 表布局及版本不变。
提供者注册 community 服务：capabilities 包含 WI_SERVICE_STREAM_DECODER=2，thread=WI_SERVICE_CONCURRENT，interfaceVersion=1。READY 后才被发现。
原生 WIC/MF 失败时，宿主按版本/提供者确定顺序调用流式 PROBE；不接受则继续静态图片扩展。它是原生不支持格式的扩展，当前没有优先劫持所有原生格式的解码器开关。

方法100 PROBE：输入 WiStreamRequest 的包内已解析路径，识别格式；不支持返回 UNSUPPORTED。
方法101 OPEN：返回 WiStreamInfo，size/version=1、非零 session、宽高/帧率/时长、PCM采样率和声道、音视频存在标记、codec。只有音频可不提供视频尺寸。
方法102 READ：在媒体线程同步调用 request.video/audio sink。每次最多一个视频帧和一个音频块，宿主立即复制。禁止持有 sink 或 input 指针供函数返回后使用。
视频是 PBGRA，最大 maxEdge；音频 s16 interleaved、1或2声道、8..192kHz，每次最多0.25秒。时间戳单位秒，同一seek段单调。
READ：0有样本，1流结束，BUSY/NOT_READY暂未就绪；真正失败返回社区错误。宿主每轮最多4次读取，PCM待播放队列最多8块，有背压，不无限预解码。
方法103 SEEK：position为秒；重置提供者位置。宿主清理旧音频和待显示帧，seek后可从新的时间戳起点继续。
方法104 CLOSE：退出时必达，包括提供者进入停止以后；CLOSE完成才释放会话对DLL的固定引用。CLOSE必须合作退出，不得无限等待。

宿主管理
播放/暂停/跳转/循环/静音/音量/速率沿 MediaEngine 原控制路径。播放帧进入既有 scene.media 绑定，PCM通过既有 waveOut输出。
提供者停止即拒绝后续读取，活动会话报清晰错误并关闭；隐藏/暂停会话仍检查提供者存活，不靠“播放中”才释放。
使用真实依赖声明的消费者会阻止提供者单独关闭；连带关闭先消费者，等待会话关闭后才卸载提供者。

示例 open-stream + open-stream-view
WIAV 为用于验证协议的2秒自定义测试格式，提供60帧64x32视频和48kHz双声道PCM。它不是某种第三方商业解码器，也不是完整视频编解码产品。
实际测试了出帧、非零音频提交计数、暂停时间线、暂停跳转、恢复、静音切换、依赖关闭。已有第三方 QOI 仍验证静态解码库路径。
未验证专业音画同步、长期播放漂移、所有速率硬件支持、直播、硬件解码和任意第三方codec。音频计数证明提交给系统设备，不冒充人工听音验证。
