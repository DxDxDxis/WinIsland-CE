# 1.2.6alpha-c2 实现与验证

## 版本与基准

- 主程序：`1.2.6alpha-c2`。
- 插件 ABI：`WINISLAND_MOD_ABI=0x00010002`，与主程序版本独立管理。
- 基准：`release/1.2.6alpha-c2-js-settings`；哈希清单为 `c1-source-hashes.txt`。
- 本修复副本额外保存了基准目录快照清单：`docs/c2-baseline-hashes.txt`；原 c2 目录未写入。

## JavaScript/GSAP 调用链

设置分类改变时，C++ 生成新的 generation 并把请求投递到后台 Job。Job 创建 QuickJS 上下文，加载固定版本 GSAP，执行 `winislandAnimation`，调用 `tween.time(seconds)` 取得属性。UI 定时器只读取原子进度，generation 不匹配的结果会丢弃。布局、绘制和命中区域仍由 C++ 更新。

脚本失败、超时、非有限值、越界值或内存限制触发时，时间轴被取消并回退宿主默认状态。JavaScript 不在窗口消息线程执行，也不依赖 CDN。

## 插件动画 ABI

`WinIslandHostApi` 末尾提供能力查询、动画注册和命令函数，旧字段顺序保持不变。动画句柄归注册插件所有，命令包括 start/cancel/pause/resume/reverse/tick；帧结构为带 size/version/sequence 的 POD，不跨 ABI 传递 STL、异常或 QuickJS 对象。

## UI 修复

- 分类按钮位于统一圆角容器内，由同一套 owner-draw 几何绘制稳定的选中胶囊和键盘焦点内框；快速点击按 generation 合并，内容控件固定在目标卡片内并分阶段入场，避免原生 HWND 横移产生白色残块。
- 所有设置下拉列表的 `WM_CTLCOLORLISTBOX` 使用深色画刷，移除系统白色矩形但保留焦点反馈。
- 顶部外扩圆弧滑块采用自绘轨道、激活段和圆形滑块，原有 0.50–1.50 范围、1.00 默认、即时预览和延迟保存不变。
- 插件管理从设置页进入同一 HWND 的子页面；嵌入页面 DPI 重新布局使用父客户区坐标。
- 修复嵌入展开中间帧仍绘制旧设置页的问题：管理器存在期间父窗口只绘制深色稳定画布，标题、说明、分类和滚动内容不再叠在管理页下方。
- 修复导航焦点提示造成的长线/竖向残留：鼠标聚焦遵循 `UISF_HIDEFOCUS`，键盘焦点使用圆角内框，不再绘制横向下划线。
- 修复圆弧拖动残影：每次 `WM_HSCROLL` 都让自绘轨道完整失效并立即提交，旧滑块像素不会留在合成视口中。
