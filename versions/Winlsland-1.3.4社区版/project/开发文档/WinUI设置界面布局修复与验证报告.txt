版本保持：1.3.3exp-winUI（实验性），数字版本 1.3.3.0。

本报告针对插件管理、模组设置、文件中转设置、复制粘贴及关于入口的上一轮需求。用户随后发出的“新增动画设置、关闭模糊效果、语言选择弹窗、删除取消翻译”需求已明确撤回，本次未实施。

原因与修改位置

插件管理及模组设置

原操作条使用默认竖向 StackPanel，三个按钮逐个向下堆叠；插件设置直接混入详情内容，没有独立、稳定的“模组设置”入口。旧 Release 客户端已实际复现，截图和结果保存在 baseline-plugins.png、baseline-mod-details.png、Baseline-results.json。

settings-winui/app.h：

- 操作条变为导入、扫描、目录、返回四个按钮。正常宽度一行，较窄宽度两排，保留稳定顺序。
- 插件摘要两排左对齐：名称、启用状态、版本和作者；运行、依赖、签名、重启及错误摘要。单行过长省略，悬停及详情保留完整信息；详情元数据也采用响应式双列。
- “模组设置”固定在卡片标题右侧，不要求先展开详情。没有已注册设置时保留禁用按钮及说明，定时刷新更新可用性。
- 模组设置覆盖当前窗口标题栏下的完整内容区，底层导航禁用，保留窗口标题栏和关闭能力。复用现有设置资源与 IPC，没有新增插件 ABI。
- 返回保留原列表对象、搜索、外层和列表滚动偏移及焦点，不重建原页面。退出延时明确回到 UI apartment，并以代次检查阻止过期回调清空新页面。
- 保留原 180 ms 淡入／淡出；降低动画时直接到最终状态。移除详情中的重复资源编辑控件。

文件中转设置

settings-winui/app.h：主要操作使用同一响应式工具条。详情文本左对齐，打开原位置、打开保存位置、取消复制、移除记录四个原有操作等宽两列。无保存副本时保留禁用位置按钮；重新定位原文件独立保留。没有修改外部文件中转窗口、拖动、吸附或复制语义。

共用布局与窄窗口

新增 settings-winui/layout.h：使用 XAML DIP 宽度计算列数，控件重排时不重新创建。工具条从四列切换为两列，极窄区域进一步退为单列以保证文本完整。文件操作等按钮支持换行，不靠压缩字体或裁切文字容纳。清理未使用的网格行，避免空行间距挤占列表。

窄窗口 NavigationView 收拢时，为页面标题保留菜单按钮空间，去掉未使用的系统返回占位，避免标题与菜单按钮重叠。

复制粘贴与翻译弹窗

settings-winui/clipboard_page.inc：

- 监听、提示、历史保存、退出清理使用相同卡片组成双列两排，说明及开关完整保留；窄窗口按可用宽度重排。
- 记录操作按钮按编辑、翻译、导出分组排列，保留保存、还原、重新读取、复制、删除、取消及导出功能。
- 移除常驻的大型服务器地址输入框，新增“其他翻译服务器地址”辅助按钮。弹窗复用 WinUI ContentDialog、项目主题资源、圆角及焦点管理，未使用 Win32 MessageBox。
- 确认时验证 http/https、主机及地址格式，通过现有剪贴板偏好 IPC 写入统一配置；保留未确认的其他偏好草稿。返回丢弃地址草稿，默认服务器规则不变。
- 翻译立即显示居中的“正在翻译中，请稍后”和 ProgressRing。请求及轮询异步执行，保留 UI apartment 切换和卡片请求序号检查。
- 成功关闭加载层，生成独立历史记录并提示用户查找，保留原文；失败关闭加载层并提供错误和重试；取消与启动、读取按顺序提交，避免旧取消误伤下一次请求。
- 使用单请求和单弹窗状态，返回或关闭时忽略过期完成；清理加载动画与弹窗引用。手动降低动画时，新增弹窗取消显示／隐藏的模板过渡，保留控件焦点及最终状态。

关于入口

settings-winui/app.h：问号改为文字右侧的矢量 FontIcon，字号从原导航图标的 20 DIP 标准尺寸改为 14 DIP（70%），与文字垂直居中，整个导航项仍保留原点击行为。

构建与实际验证

通过 PowerShell 7 执行：

powershell
./build-release.ps1 -BuildTools E:\WinIslandBuildTools


Release 设置客户端及完整内嵌主程序真实构建通过。最终主程序 --components-test 在隔离目录释放并校验运行组件成功（退出码 0）；释放出的设置 EXE 与发布设置 EXE 的 SHA-256 相同，并已连接隔离宿主成功显示插件管理页面。

实际验证环境为本机 Windows、96 DPI（100%），窗口尺寸 1000×820 和 620×820。采用 Windows UI Automation 操作真实客户端，并人工检查工具取得的原尺寸截图；不是只有静态检查或编译。脚本为 tools/ui-layout-probe.ps1，合成翻译服务为 tools/ui-layout-local-server.py，仅监听 127.0.0.1。

已通过：

- 宽窗口操作条同一行，窄窗口两排，返回按钮未被挤出。
- 可配置模组的设置按钮在收起卡片中可见，无配置模组保留禁用按钮。
- 模组设置覆盖当前内容区、没有调整窗口大小；配置保存到真实宿主资源。
- 返回后搜索与键盘焦点恢复；连续四轮进入、返回后仍可使用，无重复页面。
- 文件真实导入、保存副本完成后，详情四按钮等宽两列；窄窗口未越出边界。
- 复制粘贴四开关双列；大型地址输入已移除；地址弹窗校验、确认及返回正常。
- 本机合成翻译成功、服务器失败、取消三个分支；加载弹窗出现与清理、重试入口、独立译文记录、原文保持。
- 浅色主题下页面及服务器弹窗正确显示；降低动画时模组返回、弹窗输入和返回仍可用。
- 关于入口保持可访问，右侧问号已在截图中检查。
- 本次开始记录的 source/src 共 74 个文件 SHA-256 全部一致；没有修改灵动岛核心、外部中转核心或产品版本字段。

一次自动化断言在页面滚动尚未稳定时读取到不同的控件坐标而失败；页面截图已呈双列，等待滚动稳定后重跑整个剪贴板场景通过。最终分项结果见 Plugins-results.json、Transfer-results.json、Clipboard-results.json、Themes-results.json，不把该中间失败描述为首次全部通过。

未验证与限制

- 未实机覆盖 125%、150%、200% DPI、多显示器和跨屏 DPI 切换；DIP 自适应代码不能替代这些实测。
- 未进行逐帧动画性能或 GPU 分析，不能宣称所有快速反向操作绝无闪烁、掉帧。
- 没有用大量真实插件验证长列表滚动位置恢复；代码保留了双层滚动偏移，实测的是列表与搜索、焦点及窗口尺寸恢复。
- 本轮翻译使用本机合成 HTTP 服务，未重新验证远程云端服务及离线模型质量、下载和卸载；其宿主实现未变。
- 没有重新做全部插件卸载／重装、Windows 文件拖放、外部中转吸附等回归，它们不属于本次改动。
- 本轮完成 Release 构建，未另做 Debug 构建。
- 只实现了上一轮界面需求，没有实现已撤回的新导航、无模糊黑色模式、语言弹窗或删除取消翻译。
