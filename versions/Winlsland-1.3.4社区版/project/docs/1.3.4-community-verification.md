# WinIsland 1.3.4 社区版验证记录

本版本为 WinIsland 1.3.4 正式社区版，沿用 WinUI 3 设置客户端和 C++ 主程序架构。修改范围包含设置客户端的稳定性保护、Apple Music 设置入口、播放器识别，以及主程序灵动岛音乐行的歌词排版；没有修改插件 ABI、文件中转协议或灵动岛的业务状态机。

## 本次改动

- 紧凑音乐状态只在实际展开状态绘制独立歌词行。标题和副标题使用 DirectWrite 单行、无换行布局，按当前可用宽高缩放，超长内容使用省略号。
- 歌词文本布局按节点缓存，避免每帧重新测量；歌词行、标题和副标题仍受现有灵动岛裁剪区域约束。
- 设置客户端不再运行时修改 WinUI 共享模板的 Storyboard。降低动画改为无副作用策略，并对系统 UISettings、玻璃效果更新增加异常保护，避免持久化开关导致设置进程退出。
- Apple Music 使用单个“Apple Music 设置”对话框；空白 Token 保留已加密凭据，只有输入非空值才覆盖，地区和语言仍可单独修改。
- 自动播放器识别覆盖网易云音乐、QQ 音乐、酷狗音乐、汽水音乐和 Apple Music；手动播放器筛选保留旧索引并扩展到新来源。
- “关闭模糊效果”现在只关闭设置窗口的 Acrylic/透明层，背景使用当前浅色或深色主题的对应不透明颜色；切换主题不会被该开关禁用，子页面和弹窗同步使用同一颜色。
- SMTC 缺失 `LastUpdatedTime` 时，只要位置/时长报告有效就采用 15 秒有界同步，避免歌词被错误判定为静态；全零或过期报告仍会被拒绝。
- QRC、KRC、YRC 采用分格式逐字状态机，保留每个 syllable 的文字、开始时间和结束时间；YRC 回归覆盖 `Hel`/`lo` 及毫秒边界。音乐控制组按内容宽度居中并在窄窗口收缩，不受长标题挤压。
- 上游参考：WXRIW/Lyricify-Lyrics-Helper，commit `cabe0b71d443a9b882a35c60c4f7f21addcbe751`（2026-09-26 固定读取），移植代码位于 `source/src/lyrics_native.cpp`、`lyrics_qrc.cpp` 和 `lyrics_crypto.cpp`，许可证见 `release/licenses/Lyricify-Lyrics-Helper.txt`。
- 发布包保留 `licenses/Lyricify-Lyrics-Helper.txt`。

## 安全审计（本地静态范围）

- 当前环境没有 `cloudflare/security-auditskill`，本轮按可用的 `security-audit` 指南进行源代码静态审计；没有执行线上探测、真实账户请求或外部播放器测试。
- 未发现仓库内硬编码的 SSH 密码、私钥、带用户信息的 URL 或凭据形状的 Token。
- Apple Music 凭据通过用户 DPAPI 保护；设置 IPC 只返回“已配置”状态，不返回 Token 内容。凭据输入拒绝换行，避免注入请求头。
- 歌词 HTTP 层强制 HTTPS、禁止重定向、设置超时和 8 MiB 响应上限；请求支持取消，日志不写入 Token、Cookie 或授权请求头。
- 本地静态审计没有确认的跨信任边界安全漏洞。完整沙箱化代码审计和真实服务安全行为仍需在具备隔离环境的审计流水线中单独执行。

- Release 原生主程序编译成功。
- Release WinUI 设置客户端编译成功。
- 发布版 `release/WinIsland-1.3.4.exe` 启动隔离 `--verify` 主机成功。
- 发布版设置客户端在隔离主机管道上成功启动，窗口标题为“WinIsland · 设置”。
- 26 项原生歌词离线测试通过，包含 LRC、QRC、KRC、YRC、TTML、逐字时间、翻译、罗马音、缓存、取消、重试和 Apple Token 缺失诊断；另有 SMTC 缺失时间戳的有界同步回归。
- 正式版资源版本信息已重新生成，主程序和设置客户端的 ProductName 不再包含“实验性”；主题/模糊逻辑和音乐控制布局已通过编译回归。
- 原有主程序自检通过。
- 隔离媒体 fixture 截图确认长歌词在紧凑灵动岛内保持单行并省略，未出现截图中的底部裁切或第二行重叠。
- 75%–300% 缩放和多种窄宽度的 DirectWrite 排版回归检查通过。
