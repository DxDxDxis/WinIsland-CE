## 安装与运行

从 `dist/` 解压并运行 `WinIsland-1.3.4.exe`。请保留同目录的 `settings/`、许可证和其他运行时文件；首次运行按该版本引导确认统一数据目录。不要将不同版本的 DLL、插件或用户配置混用。
