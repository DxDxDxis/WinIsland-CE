# 顶部外扩圆弧可调版 · 1.2.5alpha-r1

本次未指定新版本号，继续使用 1.2.5alpha-r1；独立目录为 1.2.5alpha-r1-outward-adjustable。基于上一版 outward 的源码副本修改，原版源码和程序哈希已核对未变。

## 使用
运行本目录 WinIsland-1.2.5alpha-r1.exe，保留 lyric-provider 和 licenses。
设置 → 尺寸位置 → 向下滚动到“顶部外扩圆弧”。滑块范围 0.50–1.50，步长 0.01，默认 1.00；恢复默认只重置本项。恢复默认布局也会重置此项。
退出正在运行的旧程序后再启动新版，避免旧版单实例仍在运行。

## 固定基准与轮廓
- 上一版横向/纵向基准为 2/2 个布局单位；新版固定基准为 4/4.4。横向幅度约两倍，纵向略延长，Bezier 端点切线衔接水平顶部与竖直侧边。
- 倍率每次相对固定基准计算，绝不累计。0.5/1.0/1.5 对应横向 2/4/6，纵向 2.2/4.4/6.6 个布局单位。
- 默认整体缩放 1.5 时，1.0 倍每侧横向约 5.70 DIP、纵向约 6.27 DIP；再由实际 DPI 转为像素。
- 只扩大顶部外侧小范围，主体宽高、内容坐标、颜色不变。左右由同一条曲线镜像生成；顶部中间平直。
- 沿用连续轮廓插值；调节时 0.18 秒目标过渡，减少动态效果沿用现有限制。
- 绘制和命中使用 outline.h 中同一轮廓。修复旧多边形顶点取整在 200% DPI 多包含透明像素的问题，按曲线计算保守的像素行区间，合并后一次性生成窗口区域；静态帧继续缓存。

## 配置与性能
新增 XML 字段 TopArcScale，旧配置缺少该项时默认为 1.0。拒绝越界、NaN、Infinity 和带多余字符的值。
滑块不触发设置页面重排或音乐/歌词后台任务重新配置，只更新轮廓与数值；300ms 延迟合并写入后台队列，松手和关闭设置时提交最终值。

## 修改文件
source/src/core.h、core.cpp：配置、默认值、校验、持久化与构建标识。
source/src/outline.h：固定基准、横纵过渡比例与共享轮廓。
source/src/app.cpp：滑块/数值/恢复按钮、事件处理、后台保存、动画目标和命中栅格化。
source/src/tests.cpp：配置兼容、非法值、持久化、恢复与轮廓回归。

## 最终验证
环境：Windows 11 10.0.26100；MSVC x64 Release，主程序静态 CRT。
- 原生自测 68 项通过。
- 最小值 0.5：DirectComposition，100/125/150/200% 诊断 DPI，24 组。
- 默认值 1.0：DirectComposition，同上，24 组。
- 最大值 1.5：Direct2D 软件渲染，同上，24 组。
- 每组覆盖待机、音乐、展开、音乐与消息并存、独立消息和歌词；共 72 组通过，外扩可见、按钮中心命中、外部点穿透、透明像素命中采样为零。
- 72 组主体宽高、音乐区高度、通知起点与上一版结果逐项比较一致。
- 原生滑块拖动消息、键盘方向/End/边界限制、当前数值、恢复默认、即时关闭保存和进程重启恢复通过。
- 12 次连续滑块目标变更和贴合/离开状态恢复通过。
- 100/125/150/200% 设置 DPI 搭配合理窗口尺寸验证，无新增滑块/按钮重叠；截图见 source/tests/final-settings。
- 上一版 manifest 中记录的源码和 EXE 哈希均未改变。

## 实际限制
DPI 通过诊断模式配置真实渲染目标和原生控件，不等同于切换实体显示器或系统缩放设置。未实测 Windows 10、实体多显示器、低性能设备、长期运行，也没有覆盖全部倍率与渲染后端组合。
音乐、歌词和消息使用合成布局数据；本次不宣称验证了实际网易云、汽水音乐、歌词接口或 QQ 消息端到端能力。
命中检查为像素采样与按钮中心检查，并未穷举每个动画帧；没有新的 CPU/GPU 性能对比结论。
测试过程中曾发现 200% 最大值透明像素误命中并已修复重测。控件测试脚本曾误用跨进程指针消息，修正脚本后最终原生交互验证通过。

## 构建
在 source 目录执行 ./build.ps1 -OutputDirectory ../rebuilt。
需要 MSVC C++ Build Tools 和 Windows SDK；运行不需要开发环境。源码与测试记录在 source 中，运行依赖继承上一版，未增加依赖。
