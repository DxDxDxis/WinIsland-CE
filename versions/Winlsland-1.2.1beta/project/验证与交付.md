## 按钮失效与选择框的根因

旧模板虽然给 Button 设置了透明背景，但 ControlTemplate 中真正承载内容的 Border 没有背景。图标 Path 又关闭了命中，因此图标按钮的鼠标点击区不存在。此前 UIAutomation Invoke 可直接触发事件，漏掉了这条真实鼠标路径。

本次先用真实鼠标复现：点击暂停后测试媒体仍是 Playing；修复模板透明命中背景后，同一测试能使真实 Windows 媒体生产者暂停。网易云、汽水的上／下一首、暂停和恢复均再次通过鼠标测试。命令绑定当前展示来源及歌曲，并读回播放器状态；无响应仍隐藏入口。

多余框来自对所有 IsKeyboardFocused 状态都绘制边框的触发器。改为 WPF 的键盘专用 FocusVisualStyle，并补充 AdornerDecorator：鼠标点击无框，Tab 导航有可见焦点框。对照截图为 `artifacts/keyboard-stop-2/focus-comparison.png`。

## 真实音频的实现与边界

音频会话用于识别当前播放器进程、输出设备和真实静音状态；实际竖条使用 Windows 进程回环取得的 PCM 峰值，不使用随机数、正弦动画或其他应用的混合音量。采样只在内存处理，不保存真实音频。

每 60 ms 获取真实样本，六根条显示连续的六次电平；上升／下降做平滑插值。数字静音有 -80 dBFS 底限，避免 PCM 转换产生的单比特抖动被当成声音。暂停、应用数字静音、会话静音和输出静音时回落。测试使用真实播放的低音量 PCM，另一个播放器保持运行以检查来源隔离。

进程回环需要 Windows Build 20348+；本次实测 Windows 11 x64 Build 26100。普通 Windows 10 19045、受保护音频、无法映射的音频进程或采集 API 失败时，不退回模拟动画：竖条保持静态低位并提示“真实音频电平暂不可用”。独占设备、不同 Windows 版本和 DRM 内容尚未实测。

SMTC 不提供收藏／账号字段或通用歌词文本，本程序没有读取登录凭据或使用未验证的账号接口。因此不能宣称已经实现平台收藏；按照“无法可靠实现则隐藏”的要求，没有虚假的收藏按钮，也不会仅改变颜色。当前也没有自动抓取在线歌词。

播放模式适配代码支持按真实能力循环顺序、列表循环、单曲循环、随机播放，并读回确认。四种模式已通过真实 Windows 测试媒体及鼠标操作，但这不代表上述真实平台开放了该功能。入口存在时位于控制组右侧；返回失败或无确认时隐藏并短暂提示“播放器未响应”。

## 兼容性与性能修复

- 根因：音乐播放时每个 CompositionTarget.Rendering 帧都执行音频快照、六根竖条更新和几何重绘；低端机或 WPF Tier 0 软件渲染时主线程负载过高，表现为掉帧或动画看似不显示。
- 修复：新增 Compatibility.cs，检测渲染 Tier、CPU、物理内存和系统版本；完整模式按约 60 FPS，轻量模式约 30 FPS，动画仍会完成，不会被关闭。渲染节流同时应用于外壳动画和音频竖条，避免定时器堆积。
- 依赖：核心仅为 Windows 自带 .NET Framework 4.x/WPF；SMTC、进程回环音频和原生通知抑制为可选能力。没有安全必要的第三方运行库可供静默下载，缺少核心组件时会明确提示。
- 本机诊断：Windows 11 Build 26100、Render Tier 2、20 CPU、约 24GB 内存，自动使用完整模式。
- 已验证：自测 40 项、常规验证 20 项、向下消息验证 7 项均通过；轻量模式通过 WINISLAND_LIGHTWEIGHT=1 编译后运行路径检查。
- 尚未测试：朋友电脑的具体 Windows 版本、真实低内存机器、多个物理显示器及 Tier 0 GPU；这些环境会使用同一检测逻辑，但缺少现场帧率和资源数据。
