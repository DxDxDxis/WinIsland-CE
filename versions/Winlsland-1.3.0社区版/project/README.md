# WinIsland 1.3.0 社区版 · 目录与状态修复

交付主程序：`release/WinIsland-1.3.0.exe`。**现在可以只分发这个 EXE**；Electron 设置程序、歌词组件和已有第三方说明已压缩内嵌。`release/settings` 是构建与调试产物，不需要用户另外复制。不要直接运行其中的 Electron EXE。

首次启动确认数据目录；默认优先 D:\WinIsland，再按 D–Z 本地固定盘顺序选择满足权限和空间要求的位置，最后回退当前用户本地应用目录。主 EXE 留在用户双击的位置。再次启动只读取固定定位记录，数据不会跟随 EXE 移动。

- [本次验证报告](docs/1.3.0目录状态与转场验证报告.md)
- [构建身份与文件清单](build-manifest.json)

本目录是从 `../1.3.0` 完整复制的独立工作副本。原 1.3.0 和 1.2.7alpha-r1 均未改动，校验记录在 verification。较早报告描述当时版本；本次目录与转场行为以这里链接的新报告为准。

构建：`./build-release.ps1 -BuildTools E:\WinIslandBuildTools`。先构建锁定版本的 Electron，再生成带 SHA-256 文件清单的运行组件压缩包，最后内嵌进原生 EXE。插件 ABI、场景、媒体和设置 ABI 没有升级。

正常模式沿用原有单实例机制。启动新 EXE 前先从托盘正常退出旧进程，避免仍打开旧进程的设置窗口。全部测试使用 verification 下的隔离目录，没有覆盖日常插件与配置。
