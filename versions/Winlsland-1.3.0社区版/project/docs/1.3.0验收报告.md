## 未完成的环境验证与限制

- 多台物理显示器之间移动、Windows 实际 DPI 切换以及 60/120/144Hz 等不同硬件刷新率：未实测。已验证 renderer 的四档缩放、实际窗口 resize 和基于时间的动画。
- 实际中文输入法候选窗和读屏器：未人工验证；已自动化验证中文输入、composition 事件处理、原生键盘和 ARIA 状态。
- 可信证书签名“有效”样本没有新建测试证书实测；沿用原信任链校验，已验证未签名、未知包及无效签名错误分支。真实第三方模组的任意自定义回调无法据测试夹具保证。
- 正式托盘点击、日常安装目录内切换版本、在线歌词服务/第三方播放器实时会话没有在用户日常数据上操作。正式入口代码保持原路径；本次运行使用独立诊断会话。
- 重装保留旧缓存，暂不自动清理，会累积磁盘占用。它修复当前原包，不是替换不同版本的插件包。卸载保持原有保留文件语义。
- 目前 SDK 不提供设置说明字段；UI 展示实际标签/范围/key，不伪造说明。脏文本保留于窗口会话中，关闭窗口前应点保存。
- 构建过程中一次从错误工作目录启动打包，留下 `release/build-electron/settings-app` 及其空父目录（在 1.3.0 外）。清理请求被自动审批返回 `blocked by policy`，未再绕过执行。已检查没有文件，旧 r1 哈希不变；打包脚本已固定进入自身目录，后续没有此路径输出。

没有已知的阻断本机新设置界面启动或上述插件操作的未修复问题。上述环境项仍未完成，不把它们计入通过项。
