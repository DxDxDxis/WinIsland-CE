# 主程序开发者文档 — 1.2.7alpha-r1

权威 BuildId：1.2.7alpha-r1-dynamic-media-20260914。参考 1.2.7alpha 的 C++ 与 Electron 成品，独立 r1 修改。c2-open-scene、原 alpha、原 time-display 均只读。r1 中仍有历史验证目录；本次有效证据路径以实现与验证报告为准，不按目录时间推断完成。

## 工程与构建

- source/src：App、Renderer、插件宿主、scene、媒体、设置桥和已有业务。
- source/third_party：固定的 QuickJS-ng、GSAP、miniz；许可证与源码保留。
- settings-electron：原 TypeScript/main/preload/renderer/资源、锁文件，保持行为。
- settings：确认过的 Electron 运行时，必须与主 EXE 同级保留。
- lyric-provider：原歌词组件和运行 DLL，主程序原内嵌组件逻辑继续使用。
- plugins/media-fixture：真实 SDK 示例及单个 wimod；不自动加入用户 mods。
- verification：构建、自测、窗口证据；不是正常用户配置。

MSVC x64/C++20、Windows SDK，工程 build.ps1 自动寻找本机 E:\WinIslandBuildTools 或 VS。在 r1 根执行：

```powershell
& .\source\build.ps1 -OutputDirectory .\build-r1-final
& .\plugins\media-fixture\source\tests\build-skins.ps1
& .\build-release.ps1 -SkipNative
```

最后一步复制已构建 native 和保留的 settings 到 release 子目录。需要重构 Electron 时才加 -RebuildSettings（npm ci/build/package）；此任务未修改设置 UI，不要求下载重构。settings 为既有辅助 EXE，并非新建媒体框架；不要只复制主 EXE 后断言 Electron 设置可打开。

## 模块职责和调用链

| 文件 | 职责 |
|---|---|
| media_api.h | 可选 C ABI、结构、错误、能力表，产品版本与 ABI 分离 |
| media_runtime.h/.cpp | WIC/GIF 合成、MF H.264/PCM、waveOut、时钟、队列、会话、异步本地选择器 |
| media_host.inc | owner 校验、查询/绑定/控制、事件、只发布已提交节点的帧 |
| mod_system.cpp/.h | 串行插件生命周期、媒体诊断、owner revoke、pollMedia |
| scene_store.cpp/.h | 暂存/提交计划、按属性层覆盖和撤销、保留宿主帧 |
| scene_host.inc | scene/settings/media queryInterface 和回调保护 |
| scene_render.inc、render.cpp/.h | 媒体适配/裁剪、D2D bitmap缓存、设备重建、根背景 alpha |
| app.cpp | 实际窗口、根几何、输入捕获/拖动取消、状态、验证CLI |
| mod_package.cpp | 原包校验；r1 大媒体256/256/512MiB上限 |
| media_runtime_tests.cpp、mod_tests.cpp | 实际媒体与 DLL/双owner 回归 |

插件 worker 接受命令，decoder MTA 线程做文件/codec工作，UI/App只消费最新宿主复制计划，Renderer不调用DLL。chooseLocalFile独立STA，取消owner会关对话框；其他播放不会等文件选择。解码器引用与渲染帧引用分离，撤销后最后引用释放。

## 场景和输入

主业务生成实时 baseline；插件贡献通过 priority/sequence 覆盖；commit只发布本owner。disable按owner清理，不恢复旧整页。根设置 PluginManaged 才接管尺寸，Overlay不强制增高。DIP、屏幕物理坐标与媒体源像素分开；绘制/命中共用父子变换。宿主管理 capture/focus，丢失capture/节点/owner时取消拖动。根scale/rotation/shadow未开放，不得从头文件枚举存在推断已支持。

## 性能、缓存和失败

媒体bitmap尺寸不变时复用；设备丢失重建。暂停/隐藏暂停不推进解码，默认静音。队列合并过期命令/换源generation，预算详见媒体手册。单worker不隔离系统codec长时间阻塞；原生DLL捕获异常不等于可抢占死循环。状态事件允许合并，读取snapshot/info真值。

插件数据和用户媒体不与解码缓存混淆；卸载保留包/设置/日志，受依赖图约束。真实本地媒体文件不移动或删除。原安装/歌词提供者、设置协议按既有文档执行，本次不迁移日常路径。

## 验证命令

GUI subsystem EXE不能靠PowerShell直接调用得到退出码，应Start-Process -PassThru后WaitForExit。例：

```powershell
$p=Start-Process .\WinIsland-1.2.7alpha-r1.exe -ArgumentList '--media-test "<assets绝对路径>" "<报告绝对路径>"' -WindowStyle Hidden -PassThru
$p.WaitForExit(); $p.ExitCode
```

其余：--media-host-test <展开样例目录> <输出目录>；--mods-test <输出目录>（测试EXE邻近regression的examples/test-fixtures）；--scene-test/--self-test/--animation-test <报告文件>。

真实窗口用 --verify <隔离目录>，放入隔离mods；WINISLAND_SOFTWARE=1切换软件。command.txt已有诊断命令capture、dpi=1/1.25/1.5/2、media-click=<key>、mod-disable=<id>、mod-enable=<id>、music=play/music-stop；exit.request关闭该隔离进程。不可将诊断模拟DPI说成真实跨显示器移动。

record-media.ps1等CommandProcessed确认后复制完成PNG，使用真实采样时间生成ffconcat，避免复制半张PNG；录制有真实时间戳，不是生成假动画。性能短采样包含诊断I/O，不能宣传生产零开销。

## 发布与回退

根主EXE与build-r1-final必须同SHA；build-manifest明确实际位置、版本、ABI、报告。release子目录为可运行分发集合；保留settings、licenses。用户mods不纳入发布覆盖。前后快照路径和manifest见报告；回退选原工程，不对安装记录做递归清空。扩展验收、格式能力表、已知缺口必须随SDK同步。
