# 1.3.0 修复验证与交付

构建：`1.3.0-path-state-fix-20260916`。交付 EXE：`release/WinIsland-1.3.0.exe`。最终 SHA256 和源码清单见 `verification/final-artifacts.json`、`verification/source-build-sha256.json`。

## 已完成的实际修复

1. 单 EXE 压缩内嵌 Electron 与歌词完整运行目录；首次确认统一数据根目录，固定位置定位，移动 EXE 后复用；显式子进程工作目录和缓存环境。
2. 历史数据只在已知路径复制并校验，保留源文件；冲突保留目标并隔离源副本；完成标记防止重新导入已移除插件。
3. 启用选择按稳定 ID 原子持久化；退出/重载不写用户禁用；缺失/损坏记录不执行 DLL；恢复时尊重被禁用的依赖；回调异常隔离。
4. 插件页面以真实设置页为底层覆盖，输入通过 inert 分离；展开/返回 540ms → 600ms，速度为原来 90%；同步核心状态并恢复焦点/滚动。
5. 组件损坏发布到独立目录，不覆盖运行 DLL。复测发现的“切换到已有组件时活动记录未更新”也已修复。

## 实测成本与限制

原主 EXE 12,537,856 字节；新主 EXE 约 162 MiB，包含原来约 377 MiB 的运行组件。当前同组件启动至核心/插件就绪约 2.69 秒，篡改组件修复约 6.24 秒，已存在的另一组件集切换约 3.29 秒；本机单次观测，包含进程启动，不是跨机器性能保证。首次安装已实际完成，但没有单独精确计时。

尚未验证：真实多显示器之间拖动引发的 DPI 切换、不同硬件刷新率、实际 D 盘离线/盘满/ACL 拒绝和拔盘（空间与不可用路径分支已测试）、断电恢复、第三方真实插件所有私有行为、线上歌词服务的当前可用性。媒体/歌词接口未改变，但本轮未对全部在线服务重新做联网验收。没有用 UIA 去操作用户日常托盘；安装后的设置使用同一个 C++ openSettings 路径验证。

组件切换验证使用同一兼容安装协议、分别内嵌前后设置组件的测试 EXE，不能据此宣称未修改的历史 1.2.7r1/原 1.3.0 会自动使用新目录协议。完整组件哈希校验有启动成本；旧组件与崩溃遗留暂存尚未自动清理。系统管理的 Windows 文件不属于应用可归档范围。
