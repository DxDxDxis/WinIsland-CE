# WinIsland 1.2.7alpha-r1 媒体资源与皮肤扩展

权威源码为本工程 source/src，BuildId 为 1.2.7alpha-r1-dynamic-media-20260914。本文替换此前静态原型说明：当前 GIF 已合成并播放多帧，H.264 已实际解码并显示，播放控制不再是占位。生命周期 ABI 仍为 0x00010002；场景 ABI 1；winisland.media ABI 1。设置 Electron 源码、IPC 和原媒体业务保持。

## 能力和依赖

实测 Windows 11 x64 26100。WIC/MF 本身支持更早 Windows，但不代表整个产品已在旧系统验收。缺媒体组件的 Windows N/KN 需 Media Feature Pack。运行不依赖 FFmpeg、Node、浏览器、CDN、外部 codec pack。

| 格式/编码 | 系统后端、部署 | 透明/动态/音频 | 硬件与实测限制 |
|---|---|---|---|
| PNG | WIC；不附解码 DLL | PBGRA 透明，静态 | CPU 解码，D2D 绘制；透明 PNG 实测 |
| JPEG/BMP | WIC | 静态，alpha 取决于源和解码器 | EXIF 方向/ICC 未实现；JPEG 特殊样本未验收 |
| GIF | WIC 帧解码、宿主逻辑画布合成 | 透明、多帧延时、disposal 2/3、文件循环；无音频 | 4 帧逐像素匹配 Pillow 独立 oracle；最小延时 20ms |
| MP4/H.264 | Media Foundation SourceReader | 非透明视频，可选音轨 | 当前软件 RGB32 解码；320×180@30fps、3 秒 H.264/AAC 实测 |
| AAC 音轨 | MF → PCM16/44.1kHz/双声道 → waveOut | 默认静音，音量 0–1 | 真实 PCM 已提交设备；人工听感和严格 A/V 同步未验收 |
| WebP/APNG/动态 WebP/SVG/AVIF | 当前无后端 | 未支持 | 不依赖机器偶然安装的 WIC 扩展 |
| WebM/VP8/VP9/HEVC/AV1/透明视频 | 当前无后端 | 未支持 | 检查真实视频 subtype，不把 mp4 后缀等同可播 |

capabilities 返回已声明格式；加载不支持格式后异步 ERROR，不以成功受理冒充成功播放。设备丢失时 D2D bitmap 缓存清空，从宿主保留帧重建；强制 GPU 设备移除尚未验收。没有硬件视频解码。

产品新增依赖只有 Windows WIC/Media Foundation/waveOut。Pillow 12.3.0 和 imageio-ffmpeg 0.6.0 内的 FFmpeg 7.1 只用于测试样本生成，在 verification/test-tools 保留原 LICENSE，不是发行依赖。既有 QuickJS-ng、GSAP、miniz 源码和许可证保留。

## ABI 发现与共同契约

```cpp
WiMediaApi media{};
if (host->size < offsetof(WinIslandHostApi,queryInterface)+sizeof(host->queryInterface)) return;
if (host->queryInterface(host->context,WI_MEDIA_INTERFACE,WI_MEDIA_ABI,&media,sizeof(media))) return;
WiMediaCapabilities caps{sizeof(caps),1};
int rc=media.capabilities(media.context,&caps);
```

全部准确 POD、函数签名见 [SDK接口参考](SDK接口参考.md) 和 sdk/*.h。以下共同规则适用于每个函数：

- 仅在宿主串行插件 worker 回调调用；错误线程 -7、owner 停止 -8。context 由宿主绑定，不可冒充其他 owner。
- UTF-8/NUL 字符串在调用中复制，不保留调用者缓冲。结构带 size/version。输出和缓冲由调用者分配释放；不跨 DLL 传 STL、异常或 GPU 指针。
- WiMedia 为不透明 uint64 句柄，释放立即失效；重复释放和跨 owner 使用返回 NOT_FOUND。
- 时间秒，rate 倍率，volume 线性 0–1；媒体尺寸为像素，场景布局为局部 DIP。浮点必须有限。
- 同步 0 是接受命令；实际结果以 info 和异步事件为准。停用取消该 owner 媒体/输入/事件，移除节点和属性层。
- 媒体结果：OK=0, INVALID=-1, NOT_FOUND=-2, VERSION=-3, LIMIT=-4, UNSUPPORTED=-5, BUSY=-6, WRONG_THREAD=-7, OWNER_STOPPED=-8；不要混用场景错误数值。

## 每个媒体操作

下表省略重复首参 void* context；真实调用必须传 media.context。准确签名可逐字复制 SDK。

| 函数 | 输入输出、默认、异步语义 | 失败和生命周期 |
|---|---|---|
| capabilities(out) | WiMediaCapabilities{sizeof,1}；格式位集，softwareDecode=1，hardwareDecode=0，transparentVideo=0 | 过小结构/错误版本 VERSION |
| load(relativePath,out) | 包根相对路径；输出 LOADING 句柄，默认最大边 1920 | 参数同步检查，文件/解码错误异步 ERROR |
| loadFrom(kind,path,edge,out) | PACKAGE=0 或 PLUGIN_DATA=1；最大边 32–4096；相对对应根 | 非法来源、绝对路径、..、ADS 拒绝；canonical 逃逸异步失败 |
| chooseLocalFile(edge,out) | 独立 STA 系统文件选择器；先返回 LOADING，选定后解码 | 全局同时一个选择器，BUSY；取消为 ERROR/selection.cancelled；release 取消对话框 |
| info(handle,out) | 当前状态/尺寸/时间/代次/帧序号/错误 | 支持到 originalWidth 前的旧结构前缀，只拷贝调用方容量；NOT_FOUND/VERSION |
| bind(handle,element) | 自有节点；同 owner 可一源多节点，节点仅一个媒体写入者；scene.commit 后发布 | 非自有/不存在节点 NOT_FOUND |
| unbind(handle,element) | 清该节点暂存帧，scene.commit 发布；资源仍可再用 | 未绑定 NOT_FOUND，不自动 release |
| play(handle) | ready/paused/stopped/ended → playing，ended 从 0 重启 | 静态图 UNSUPPORTED，loading 时命令等加载后执行 |
| pause(handle) | 冻结进度与画面，恢复继续当前进度 | 静态图 UNSUPPORTED |
| stop(handle) | stopped、归零、请求首帧，不释放 | 静态图 UNSUPPORTED |
| seek(handle,seconds) | 非负，限制到总时长；seek.completed 表示目标帧已准备 | 非有限/负数 INVALID；静态图 UNSUPPORTED |
| setLoop(handle,0/1) | 显式策略覆盖 GIF 文件循环；视频默认循环 | 非布尔 INVALID |
| setRate(handle,rate) | 0.1–4，默认 1，由宿主单调时钟推进 | 已打开的音频设备拒绝倍率时保持旧倍率并发control.error；初始化音频时倍率不支持则静音/audio.error |
| setMuted(handle,0/1) | 默认 1，取消静音才打开音频设备；静音清 PCM 队列 | 无音轨 UNSUPPORTED；设备失败异步 audio.error |
| setVolume(handle,value) | 0–1，默认 1，只设置本会话，不改系统主音量 | 无音轨 UNSUPPORTED，范围错误 INVALID |
| setHiddenPolicy(handle,policy) | PAUSE_HIDDEN=0 默认；CONTINUE_HIDDEN=1 时钟/音频继续、隐藏不发布新画面 | 非法枚举 INVALID；恢复显示追赶时间 |
| replaceSource(handle,relativePath) | 包内换源，generation 增加，清旧命令；新帧前保留最后好帧 | 新源 ERROR 保留上一张帧但不继续旧 decoder |
| release(handle) | 句柄立即失效，取消加载/选择器，清绑定并发布撤销 | COM/音频清理在 decoder worker，最后帧引用自然释放 |

WiMediaInfo 字段：width/height 是解码像素；originalWidth/originalHeight 是源尺寸；duration 秒；GIF frameCount 是帧数，视频不预扫描总帧数，0 不表示没视频；frameRate 来自元数据；hasAlpha 表示透明像素；hasAudio 有音轨；audioSupported 可尝试输出；muted 是真实状态；audioSamplesSubmitted 是已提交 PCM 样本数，不保证人工听感；frameSequence 仅发布新帧时递增；generation 换源递增。loading 期间宽高/时长未准备，不能据零值报成功或失败。

## 状态、事件与帧

LOADING → READY → PLAYING/PAUSED/STOPPED/ENDED；失败进入 ERROR；release 后返回 NOT_FOUND，不保留可操作的 RELEASED 对象。

通过旧 host.add(WI_EVENT) 订阅 media.changed 或具体主题：media.ready/playing/paused/stopped/ended/error/seek.completed/loop/audio.error/selection.pending/selection.cancelled。负载为 resource、generation、state、position。当前是最新状态通知，轮询间非常快的中间状态可能合并，不保证每个短暂事件必达；回调读取 info 真值。事件仅发给资源 owner，回调前校验 generation/owner。回调失败停用对应插件，不保证原生死循环可抢占。

## 媒体进入场景

```cpp
WiElement root=0,image=0;
scene.find(scene.context,"island",&root);
scene.create(scene.context,WI_IMAGE,"skin.background",root,&image);
WiPropertyValue rect{sizeof(rect),1};
rect.number[2]=640; rect.number[3]=352;
scene.set(scene.context,image,WI_RECT,&rect,10);
WiMedia resource=0;
media.load(media.context,"assets/motion.mp4",&resource);
media.bind(media.context,resource,image);
scene.commit(scene.context);
// 收到 ready 后读取 info 并 play；不得在 UI 等待。
```

媒体节点进入既有父子树，与 Text/Button/Slider/CustomDraw 共用变换、透明度、z、裁剪和输入几何。WI_MEDIA_FIT：0 stretch 默认、1 contain、2 cover。WI_MEDIA_CROP：number[0..3] 为源归一化 x/y/w/h，默认全图，w/h>0、区域不能越过1；先裁源再适配目标。

根 island 可设置 WI_SIZE_MODE=PLUGIN_MANAGED、WI_RECT=(0,0,w,h)、WI_POSITION（屏幕物理像素）、背景 RGBA、圆角、边框、可见/展开。Overlay 保留宿主尺寸，没有显示一行文字就强制扩容。根 scale/rotation/shadow 仍返回 UNSUPPORTED；子节点 scale/rotation 已参与绘制和逆变换命中。无任意 alpha 遮罩、无媒体透明像素阈值命中；圆角/矩形裁剪、透明背景配合 PNG 可形成非矩形视觉，输入仍按登记几何。整体窗口受显示器工作区约束，复杂自动布局需插件计算。禁止把子节点旋转宣传为任意整窗旋转。

原生 key、基础属性与尺寸模式见开放场景API.md。修改链选 (priority,sequence) 最大值；同 owner 同属性保留最新贡献。清 owner 后从实时基线与剩余层重算，不恢复启动旧快照。remove 自有节点为销毁，对其他节点为可撤销隐藏；可隐藏原生再插入自有内容。

## 输入与渲染

支持 pointer enter/leave/move/down/up/click/wheel、key down/up、focus gained/lost、text input；r1 新增 drag start/update/end/cancel。回调在 worker，0 未处理、1 已处理，按层级/几何/blockInput 分发。宿主 pointer capture 保持越界拖动；失焦、节点删除、停用时取消。事件 x/y 为目标局部 DIP，使用渲染矩阵逆变换；拖插件进度条不执行原生窗口拖动。无完整 IME、触摸、手写笔、全局快捷键；不暴露裸 D2D/D3D 指针。物理越窗拖动尚需人工验收，自动回调测试不能替代。

CustomDraw 使用宿主复制的命令/位图；绘图回调在 worker，GPU 线程不执行 DLL。节点 bitmap 按尺寸缓存，尺寸不变 CopyFromMemory，target 重建后从宿主帧重建缓存。

## 线程、预算和清理

调用链：DLL worker → owner/参数校验 → 有界队列 → 独立 MTA decoder(WIC/MF/waveOut) → immutable PBGRA frame+generation → worker 仅更新已绑定帧槽 → App 布局 → D2D bitmap → DirectComposition/软件显示。未提交其他属性不会被媒体帧轮询顺带发布。

最多8个活动/待释放会话；每会话最多16条按命令类型合并；源文件512MiB；源图64MP；GIF缓存64MiB/资源；最大边默认1920、可选32–4096；视频单帧最多4096²；音频最多6块，每块最多1MiB。不是进程总内存硬上限，MF内部/GPU/临时合成另占内存。

播放时 decoder 约10ms推进，loader 有媒体时约16ms取快照；无活动播放/seek时 decoder 条件变量等待。示例100ms状态刷新，值不变不提交。单 decoder worker 的慢系统解码可能推迟其他媒体，当前无 codec 强制中断或进程隔离。

卸载停止 owner 新请求，移除事件/输入/定时器/覆盖层，release 立即失效并取消，decoder worker 清 COM/waveOut，最后一个宿主帧引用释放后销毁。资源可同owner多节点共享，无跨插件裸句柄共享；关闭A不释放B的decoder。

## 包、路径与样例

仍需 .wimod 根 mod.json+x64 DLL；资源皮肤和功能皮肤共用插件入口，不支持无代码JSON包。包256MiB、单成员256MiB、总展开512MiB，旧宿主可能拒绝更大包。canonical 逐组件校验阻止 junction/路径逃逸；系统文件选择器授权的本地文件不移动、不删除。

权威示例 plugins/media-fixture/source/tests/skin-example.cpp 包含PNG/GIF/H.264、播放/暂停/seek/stop/loop/换源/本地文件、可拖动PNG和可键盘操作进度条。build-skins.ps1 自动同步SDK、构建DLL和单个wimod；assets已提供。generate-assets.py(Pillow)及测试ffmpeg可重新生成样本，不是运行依赖。

```powershell
& .\plugins\media-fixture\source\tests\build-skins.ps1
& .\source\build.ps1 -OutputDirectory .\build-r1-final
```

示例实测旧函数表前缀、旧info缓冲哨兵、缺失扩展、错误线程返回。用户导入单个wimod即可，不需要手动解压DLL。

## 排查和回退

1. 核对EXE BuildId和SHA，旧静态中间版不会播放视频。
2. 查mod.log区分加载/ABI失败与resource/generation/error。
3. load=0后查info；ERROR看路径、HRESULT、Media Feature Pack。
4. READY无画面查bind自有节点、commit、矩形/父可见/opacity/z。
5. PLAYING不动查frameSequence、隐藏策略、pause、seek代次。
6. 音轨故障查audio.error/muted，失败保留视频并静音。
7. 停用残留查owner，禁止清空其他插件或整页恢复。

验证与缺口见实施与验证报告。回退运行旧目录EXE；旧工程、time-display插件和日常数据不改。新SDK不得被当作旧宿主能力证明。
