## 实际原因与修改

1. **方向错误**：先前入场固定为 `translateX(24px)`，退出固定向左。现在 `navigate()` 在更新 page 前统一计算 `sign(target-current)`，交给 `showPanel()`。向后选择时从左进入、向右退出；重复当前分类不重建、不启动页面或底板动画。
2. **开关触发相邻控件闪烁**：原公共 `action()` 对全部 `[data-core]` 设置 disabled，再恢复 enabled；白色输入框会经过灰色禁用样式。MutationObserver 捕获了 `seconds`、`fps` 及其按钮的 disabled 往返变化。**没有发现设置页被销毁重建**。
3. **草稿丢失**：原提交前后调用全字段 `displayValues()`。复现中，未保存的通知时间从 `12.75` 被重写成核心的 `4`，节点仍是原节点。现在 `write(patch)` 只同步 patch 对应控件；显式“重新读取状态”和“恢复默认布局”仍按原功能刷新对应完整状态。
4. **并发开关**：宿主开关不再进入全页禁用路径。内部保留核心快照/revision，每次提交单字段；一项请求进行中，每字段最多合并一项最新意图。已确认 checked/ARIA 与待提交意图区分，失败读取核心并只回退该字段。其他保存动作等待队列，邻近输入仍可编辑。轮询不与开关写入竞争。
5. **错误造成布局跳动**：错误反馈改为独立定位的可访问提示，不再把顶部布局向下推移。没有用遮罩、整页显隐或禁止重绘掩盖故障。
6. **重开滚动被截短**：初次恢复时能力说明/显示器列表尚未加载，浏览器提前限制了 scrollTop。现在在真实设置与能力首次加载完成后再恢复最终滚动和焦点。只存 UI 分类/滚动/焦点；实际设置仍由 C++ 读取。

## 动画与控件方案

- 底板 260ms，内容 220ms / 24px，开关 200ms，下拉 180ms；统一 `cubic-bezier(.2,.75,.25,1)`。集中在 style.css 的 `--motion-*`，由 Web Animations 读取。
- 底板只有一个。中断时读取当前显示几何，再取消旧实例并衔接新目标；不按旧起点重播。
- 当前真实页面立即挂载、索引与 ARIA 立即更新。旧页面的无 ID、无事件副本只负责退出视觉，inert、aria-hidden、pointer-events:none；完成或中断即删除。真实非当前页面脱离 DOM 并 inert，有限缓存用于保留草稿，不能接收鼠标/Tab。没有每帧布局读取、递增队列或动画轮询线程。
- 下拉使用当前 Electron 已验证支持的 `appearance: base-select` / `::picker(select)`。浏览器保留真实 select/options、键盘、typeahead、顶层弹出、锚点翻转和焦点语义；CSS 负责展开/关闭，不伪造 DOM 业务值，也不增加 preload 权限。
- 插件入口实测从 82 × 36.390625 CSS px 改为 164 × 54.578125（像素舍入），受 max-width:100% 限制。插件进入/返回逻辑继续同一窗口直接显示，没有重写宿主操作。
- 系统减少动态效果时立即完成设置过渡；不改变 C++ reducedMotion、QuickJS、GSAP、灵动岛帧率或插件动画服务。
