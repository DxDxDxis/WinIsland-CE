# WinIsland 插件系统开发者文档

版本基线：`1.2.7alpha-r1-dynamic-media-20260914`

本文档从插件制作、打包、加载、运行、场景修改、设置扩展、卸载和故障排查完整说明 WinIsland 插件系统。实际接口以同目录 `开放场景API.md`、`source/src/mod_api.h` 和 `source/src/scene_api.h` 为准；文档中的计划内容不代表已经实现。

## 1. 系统定位

插件必须依赖 WinIsland 主程序，不能作为独立程序运行。主程序负责加载 DLL、提供 API、维护场景、执行绘制、分发输入、保存插件设置和管理生命周期。插件负责自己的业务逻辑、资源注册、布局决定和错误处理。

当前插件分为两层：旧资源 API（设置、按钮、图层、替换、事件、定时器等）用于兼容旧插件；开放场景 API 用于创建和修改通用灵动岛元素。原生设置窗口基础框架、安装器、加载器、安全校验、托盘和权限管理仍属于宿主。

## 2. 插件包格式

最终文件扩展名必须为 `.wimod`，本质是受限 ZIP 包。最小结构如下：

```text
my-mod/
├─ mod.json
└─ bin/my-mod.dll
```

可选文件包括 `assets/`、`README.md`、`LICENSE`、动画脚本和插件自有数据。`mod.json` 必须在包根目录，`entry` 必须指向包内 x64 DLL。禁止 `..`、符号链接、重复路径、加密 ZIP 和不受支持的压缩格式。签名包必须同时包含 `signature.json` 与 `signature.p7s`。

## 3. 清单字段

```json
{
  "id": "my-mod",
  "name": "我的插件",
  "version": "1.0.0",
  "author": "作者",
  "description": "功能简介",
  "entry": "bin/my-mod.dll",
  "apiVersion": 1,
  "gameVersion": ">=1.2.7alpha-r1 <1.3.0",
  "dependencies": []
}
```

`id` 是稳定唯一标识，不能随版本改变；`name`、`author` 和 `description` 会显示在插件管理界面；`version` 用于依赖匹配和缓存目录；`apiVersion` 表示清单所使用的插件协议；`gameVersion` 是兼容说明，不替代 ABI 检查；`dependencies` 可写字符串或带版本范围的依赖对象，具体格式以当前解析器为准。

## 4. 构建与入口

插件使用 Windows x64 DLL，必须导出：

```cpp
extern "C" uint32_t WinIsland_ModAbi();
extern "C" IWinIslandMod* WinIsland_CreateMod(const WinIslandHostApi* host);
```

ABI 返回当前 `WINISLAND_MOD_ABI`。`WinIsland_CreateMod` 返回包含 `onLoad`、`onEnable`、`onDisable`、`onUnload` 和 `destroy` 的 POD 表。字符串使用 UTF-8；不得跨 DLL 传递 STL、C++ 异常、虚表或由一方分配另一方释放的内存。

## 5. 加载和生命周期

```text
扫描 .wimod
→ 清单、ZIP、x64 PE、依赖和签名校验
→ 解压到按 id/version/hash 区分的 mod-cache
→ LoadLibrary
→ ABI 和工厂检查
→ onLoad
→ onEnable
→ 运行
→ onDisable
→ onUnload
→ destroy
→ FreeLibrary
```

`onLoad` 适合初始化上下文；`onEnable` 注册运行资源并读取设置；`onDisable` 必须停止新回调并清理可见资源；`onUnload` 完成最终释放。重复启用、禁用和重新加载必须幂等。

## 6. 旧资源 API

旧 API 资源类型包括 `WI_SETTING`、`WI_BUTTON`、`WI_LAYER`、`WI_REPLACE`、`WI_TIMER`、`WI_EVENT`、`WI_TASK`、`WI_HOOK` 和 `WI_ANIMATION`。这些资源仍按旧语义运行，不能把旧 `WI_LAYER` 自动当作开放场景节点。所有资源句柄均由宿主分配，插件必须保存并在停用时移除。

## 7. 开放场景 API

通过 `host->queryInterface("winisland.scene", 1)` 获取 `WiSceneApi`。典型流程为：读取快照、创建或查找节点、设置属性、注册输入/绘图、`commit` 提交、根据事件再次读取快照。支持 Container、Text、Image、Icon、Button、Shape、Progress、Slider、Input 和 CustomDraw。

节点属性包括父子关系、矩形、锚点、边距、圆角、背景/边框/文字颜色、字体、字号、透明度、缩放、旋转、裁剪、z 顺序、可见性和输入开关。所有结构均带 `size/version`，错误返回 `NOT_FOUND`、`UNSUPPORTED`、`CONFLICT`、`LIMIT` 等明确结果。

## 8. 灵动岛尺寸和布局

根节点 `island` 支持 `HostManaged`、`Overlay`、`PluginManaged` 和 `Intrinsic`。Overlay 不增加尺寸；PluginManaged 使用插件提交的根矩形；Intrinsic 根据符合条件的节点包围盒测量。复杂旋转或嵌套布局应由插件自行计算。插件可以自由决定自己的元素位置和尺寸，但多个插件冲突时遵循 priority + sequence。

## 9. 场景状态和事件

快照提供待机、音乐、播放、歌词、通知、展开、设置页面、减少动画、软件渲染、DPI、岛位置/尺寸、可见节点、焦点和代次。事件包含 `scene.idle`、`scene.music.started/changed/stopped`、`scene.lyric.started/changed/stopped`、`scene.notice.shown/hidden`、`scene.expanded/collapsed`、`scene.layout.changed` 和 `scene.input.changed`。事件只提示变化，回调中必须重新读取快照。

## 10. 绘图和输入

标准元素由宿主 Direct2D 绘制。CustomDraw 使用宿主复制的绘图命令或 BGRA 位图；`onDraw` 在加载器工作线程执行，渲染线程不持有插件内存。输入支持鼠标、滚轮、键盘、焦点和文本事件，命中测试会考虑父级裁剪与变换。当前不提供裸 HWND、GPU 上下文、完整 IME、剪贴板或系统级快捷键。

## 11. 设置扩展

通过 `winisland.settings` 注册插件专属文本、数字、开关和选项设置。设置保存于插件自己的 `settings.xml`，必须声明默认值、范围或选项列表。原生设置窗口框架不能直接修改；插件可提供自己的设置页和插件管理中的配置项。

## 12. 可逆修改和共存

每个修改记录 owner、目标、属性、旧值、优先级和序号。禁用插件时只清理本 owner，并重新计算其余插件和宿主基线；禁止保存整页快照后整体恢复。删除其他插件的父节点不会销毁其子节点。句柄销毁后不复用，旧输入按代次丢弃。

## 13. 性能、线程和限制

插件回调在宿主规定线程串行执行；不得阻塞主循环，不得创建无法停止的线程。当前原生回调超过约 50ms 只能记录，不能安全抢占。节点、属性、绘图命令和位图有数量及内存上限，超过限制返回 `LIMIT`。同进程 DLL 的死循环、任意内存破坏和崩溃不能被安全隔离。

## 14. 测试清单

至少测试：全新安装、依赖顺序、签名、重复 ID、加载失败、启停重载、场景 create/set/commit、文本显示、节点删除、两个 owner 覆盖、状态开始与结束、输入命中、DPI、窗口恢复、资源上限和主程序退出。发布时附 `.wimod`、README、许可证、构建方式、ABI 版本和已知限制。


## 媒体资源（r1）

使用 `winisland.media` 查询能力并加载 `.wimod` 包内的 PNG/JPEG/BMP/GIF/MP4-H.264，再绑定到自有 `WI_IMAGE` 节点。资源按 owner 自动释放；当前 GIF 完整合成多帧，H.264 由 MF 解码连续帧，媒体控制通过独立解码线程执行。WebP/APNG 和其他视频 codec 未支持。详见《媒体资源与皮肤扩展》及 `source/src/media_api.h`。

## r1 SDK、媒体与发行补充章节

本手册与《SDK接口参考》《媒体资源与皮肤扩展》《开放场景API》一起构成完整插件参考。SDK在根sdk目录；每个媒体操作的参数、线程、失败/异步/停用语义见媒体手册逐行合同。

推荐从 plugins/media-fixture/source/tests/skin-example.cpp 开始，复制自己的独立工程，替换id/key/资源；不要修改time-display或宿主私有内存。build-skins.ps1自动复制权威SDK并生成真实wimod。示例包同时展示静态/动图/视频/按钮/进度条/拖动，没有另建安装器。

来源可为包内、插件数据、或用户通过宿主选择器指定的本地文件。正常用户仅导入单个wimod。禁止绝对包路径、..、符号链接和ADS，源文件不由卸载删除。新包上限256MiB，展开512MiB；旧宿主可能拒绝，需声明兼容范围。

设置仍通过winisland.settings.define/read/write注册文本、数字、开关、选择；类型、范围和默认值由宿主验证。读取时使用足够UTF-8缓冲，写入成功后更新真实场景，不能只写文件；调用失败保持旧值。更新插件需自行兼容已有自有配置，不迁移全局用户数据。

不支持WebP/APNG等格式、根整体scale/rotation/shadow、完整IME、直接GPU上下文、透明像素命中、无DLL资源包、网络媒体；使用capabilities和明确错误做降级。其他功能可以继续使用旧资源/scene/settings/animation接口。
