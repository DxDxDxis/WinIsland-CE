# WinIsland 1.2.2beta

交付文件：`../1.2.2beta/WinIsland-1.2.2beta.exe`。先从托盘退出旧版，再双击新版。可以只复制此 EXE 给另一台兼容的 Windows 电脑，无需源码或额外 DLL。

保留原有 .NET Framework / WPF 架构，使用 Windows 自带运行库、SQLite 和媒体接口。已在 Windows 11 x64、Build 26100 实测。默认跟随 Windows/WPF 渲染节奏；低于 4GB、双核或软件渲染时默认目标为 60 FPS，手动帧率优先。基础媒体信息使用 Windows 10 1809+ 的 SMTC；进程回环音频要求 Windows Build 20348+。其他系统尚未实测。无需 .NET SDK 或额外 DLL，但 EXE 仍依赖系统的 .NET Framework/WPF；缺少 CLR 时程序自身无法运行检查或修复，需要使用 Microsoft 官方安装程序。没有新增运行库下载或强制升级流程。

## 使用

- 播放音乐后基础胶囊自然舒展。紧凑态为 460.46 × 48.384 DIP，展开高 105／121.8 DIP；歌词可在 460.46–616 DIP 内自适应，窄屏进一步限宽。点击歌曲区展开控制。暂停或停止连续 10 秒后平滑收回，恢复播放再展开。
- 上一首、播放／暂停、下一首已修复真实鼠标点击。图标缩小、点击区域保留；鼠标无选择框，键盘 Tab 保留焦点提示。控制依实际能力显示，未确认生效的操作隐藏。
- 六根细竖条来自当前播放器进程的真实音频样本，展示连续音量历史，不是频谱或预设动画。暂停、数字静音或系统静音时回落；系统无法提供进程回环采集时保持静态并显示不可用提示。
- QQ 等应用产生的 Windows 通知从音乐外壳底部向下展开，音乐保持在上方，按托盘设置的时长依次收起。音乐不会替换消息。
- 托盘“设置”显示 `1.2.2beta`，保留常驻、隐藏系统横幅和通知停驻时间，新增“动画帧率”，修改自动保存并立即生效。
- 播放器必须向 Windows 提供 SMTC 信息；网易云需要开启其系统媒体控件选项。
- SMTC 没有通用歌词字段。播放器提供可靠进度时，可在设置中载入当前歌曲的 LRC；歌词同时用于紧凑态和展开态。切歌清空，缺失时回退为歌手或简短提示。没有自动抓取在线歌词。
- 收藏没有可靠的通用状态／写入接口，当前三平台均不显示收藏入口。播放模式仅在 SMTC 明确提供状态和写入能力时出现；本机网易云、汽水未提供这些能力，已隐藏。

## QQ 消息范围

只读当前用户 Windows 通知中心，不读取 QQ 聊天数据库。QQ 前台、屏蔽会话、关闭系统通知或仅显示自绘提示时，可能根本不写入 Windows 通知中心，本程序便无法取得消息。请启用 Windows 和 QQ 自身的系统通知，并确认受影响消息是否进入通知中心。

此前已修复队列丢弃、初始化漏收、去重和异步过期回调问题；本次保留这些处理。真实 Windows 通知和连续 12 条合成消息回归通过；完整 QQ 前台／后台／托盘／重启及长期运行场景未实测，见 [验证与交付.md](验证与交付.md)。

## 动画帧率

右键托盘 → 设置 → 动画帧率。输入 `0` 使用默认策略，普通环境跟随系统渲染事件且不额外限帧，低性能环境目标为 `60 FPS`。输入 `30–240` 的整数手动指定目标上限，立即生效并在重启后保留，也覆盖低性能默认值。无效输入保持当前值并提示，离开输入框时恢复有效值。

帧率同时控制容器动画和真实音频竖条；暂停回落速度按时间计算。实际呈现受屏幕刷新率、Windows/WPF 和硬件负载限制，设置更高数字不能保证达到该帧率。旧配置缺少 `FrameRate` 时默认使用 `0`，不会改动原有设置或歌词。

## 设置与文件

- 原 `WinIsland`、`WinIsland-1.1`、`1.1.1（社区版）` 保留；本版源码位于 `WinIsland-1.1.2社区版`。
- 设置：`%LOCALAPPDATA%\WinIsland\settings.xml`；歌词：同目录 `lyrics` 子目录。
- 诊断：同目录 `diagnostics.log`，不保存通知正文。
- 沿用原版自启动行为：正常启动注册当前用户登录启动项；托盘“退出”删除该项。移动 EXE 后重新打开更新路径。
- 隐藏系统横幅时有一个恢复辅助进程，也由同一 EXE 启动。退出、关闭开关或通知读取异常时恢复横幅，不需要另发辅助文件。

## 构建与验证

Windows PowerShell 5.1，无需 SDK 或 NuGet：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -OutputDirectory .\artifacts\local-build
$exe = (Resolve-Path .\artifacts\local-build\WinIsland-1.2.2beta.exe).Path
Start-Process $exe -ArgumentList '--self-test', '.\artifacts\self-test.txt' -Wait
.\verify.ps1 -Executable $exe -OutputDirectory "$PWD\artifacts\verify-new"
.\verify-media.ps1 -Executable $exe -OutputDirectory "$PWD\artifacts\media-new"
```

每次测试用新输出目录。诊断运行不改变用户设置与自启动。正常使用 EXE 无需参数。设计见 [DESIGN.md](DESIGN.md)，修改清单和测试边界见 [验证与交付.md](验证与交付.md)。
