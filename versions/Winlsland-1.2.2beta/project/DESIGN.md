# Design System: WinIsland 1.2.2beta

## Overview

记录日期：2026-09-06。依据当前 `MusicView.cs`、`IslandWindow.cs`、`SettingsWindow.cs`，并核对 `MediaSessions.cs`、`Settings.cs` 与 `artifacts/media-refinement-1/review.png`。这是已实现界面的记录，不是新页面或新主题方案。

界面身份是主显示器顶部居中的黑色胶囊：白色主要文字、灰色次要信息、浅蓝色六根真实音量历史竖条。参考 ColorOS 16 的连续形状过渡，保留原生 WPF 的内容、控件和桌面行为。设置窗口使用已有的浅色原生窗口。

## Colors

颜色值以上方 frontmatter 为准，对应现有 WPF 颜色。

- 浅蓝 `playback-bars` 表示播放活动；相近的 `progress` 表示时间进度。它们不是全局按钮主色。
- `island` 是通知和音乐容器的实心黑底；`text-primary` 用于标题、播放图标与音乐键盘焦点边框。
- `text-notice`、`text-artist`、`text-lyric`、`text-timing` 分别区分通知正文、歌手、歌词与时间。封面缺失时使用 `artwork-placeholder` 和白色音符。
- 音乐控件悬停使用 `music-hover`；进度条底轨使用 `progress-track`。
- 设置窗口使用 `settings-background`，白色设置行和输入框，辅以 `settings-muted`、`settings-border` 与 `input-border`。开关启用态为 `switch-on`，关闭态为 `switch-off`，键盘焦点为 `switch-focus`，校验错误为 `validation-error`。

## Typography

字体统一为 WPF `FontFamily("Segoe UI, Microsoft YaHei UI")`。下面的字号和布局数值均为 WPF 设备无关单位（DIP），不是截图物理像素；未显式设置的行高、字重沿用控件默认值。

| 用途 | 字号 / 字重 | 行为 |
| --- | --- | --- |
| 通知标题 | 14 / Bold | 换行，行高 19.2，受可用高度限制并截断 |
| 通知正文 | 12 / 默认 | 换行，行高 17.6，空正文折叠 |
| 歌曲标题 | 12.5 / SemiBold | 单行，超长省略 |
| 歌手／当前歌词 | 10.5 / 默认 | 单行，超长省略，与标题间隔 1 |
| 同步歌词 | 12 / 默认 | 居中单行，高度 16，超长省略 |
| 播放时间 | 10 / 默认 | 右对齐，格式 `mm:ss / mm:ss` |
| 设置窗口标题 | 26 / SemiBold | 产品名与版本分列 |
| 设置行标题 / 提示 | 14 / Medium；11 / 默认 | 左侧标题与辅助说明 |
| 设置说明与校验提示 | 12 / 默认 | 使用次要色或错误色 |

## Layout

本轮以先前音乐紧凑态 364 × 57.6 为基准，高度缩至 80%，基础宽度增加 15%；基础灵动岛和通知维持原尺寸。标准尺寸如下；窄屏下音乐宽度可按显示器可用宽度缩小。

| 状态 | 宽 × 高 | 圆角 |
| --- | --- | --- |
| 常驻基础胶囊 | 180.4 × 29.92 | 13.6 |
| 音乐紧凑态 | 460.46–616 × 48.384 | 20 |
| 音乐展开态 | 460.46–616 × 105／121.8 | 22 |
| 通知 | 内容测量，宽 180.4–616，最小高 52.8 | 目标 28，最多为高度一半 |

- 胶囊位于主显示器顶部下方 8 DIP，水平居中，按显示器 DPI 定位。通知宽度还受屏幕宽度减 32 限制；音乐首选最小宽度 418.6、最大 616，受屏幕空间进一步限宽；按整首 LRC 的最长行预留宽度，逐行切换不改变宽度。
- 音乐在上、通知从底部向下延伸，二者属于同一个连续外壳，没有独立浮窗或间距。通知收回保持音乐的展开状态。
- 音乐内边距左右 14、上下 7.04；头部高 32。封面为 28 方形，左列宽 32，文字左右间隔 9／10。
- 展开区与头部间隔 3，顺序为歌词、控制、2 DIP 进度条、时间。无歌词显示简短提示，无时间轴时折叠进度与时间，高度从 121.8 降为 105。不支持的按钮直接折叠。
- 通知左右内边距 24，上下预留各 16.8，正文距标题 6.4。容器按文本长度测宽；与音乐并存时限制通知高度以容纳下方音乐。
- 设置窗口为 552 × 600，受当前工作区限宽限高，内容可纵向滚动；新增动画帧率行。内容外边距为左/右 26、上 22、下 18。设置行间距 8，行内边距为左右 16、上下 12；说明文字可换行。

## Elevation & Depth

灵动岛使用透明宿主窗口和实心黑色圆角容器，无显式阴影、模糊或玻璃效果。音乐与通知共用外壳，用一条细分隔线区分区域。设置窗口依靠浅底、白色行容器和 1 DIP 边框区分区域；系统窗口装饰由 Windows 管理。

## Shapes

基础胶囊、通知和音乐面板共享连续圆角矩形语言。动画同时更新宽、高、圆角和对应裁剪轮廓，内容受轮廓裁剪。封面圆角为 6；音乐按钮和设置行圆角为 10。真实音量历史为六根宽 2、高 14、端部圆角 1 的竖条，以底边为缩放原点。

## Components

### 灵动岛与通知

置顶且不在任务栏出现。没有音乐时，窗口不接收激活并让鼠标穿透；有音乐时只让音乐区域命中，通知区域仍穿透。锁屏、会话或电源暂停时隐藏并清空当前展示。

通知进入为 0.52 秒，常规恢复基础状态为 0.4 秒；同条通知内容更新为 0.25 秒，并存布局调整为 0.3 秒。内容淡入在形变进度约 16% 后开始，退出时先淡出文字。停驻计时从展开完成后开始，默认 4 秒，可设 0.1–3600 秒。关闭常驻后，无通知且无音乐时整体向上隐藏，偏移为 −43.2。

### 音乐与连续过渡

点击头部展开或收起；标题、封面、歌手／当前歌词和六根音量条始终位于头部。进入从当前胶囊形状变为音乐面板（0.56 秒），退出恢复胶囊或收至零高（0.46 秒）；紧凑态与展开态切换为 0.42 秒。新动画读取当前宽、高、圆角和内容透明度作为起点，因此可在过渡中打断并重新定向。

形变采用归一化阻尼曲线 `Ease(t) = (1 − (1 + 9t)e^(−9t)) / (1 − 10e^(−9))`。音乐内容淡入延后至约 18% 进度，淡出先于形状收拢。关闭 Windows 客户区动画时，形变时长降至 0.001 秒；音量条属于实时数据反馈，仍显示真实测量。

六根竖条使用 Windows 进程回环取得的连续真实 PCM 峰值，60 ms 更新，应用 -80 dBFS 数字静音底限，再以对数幅度展示。窗口不生成音量波形，不录制音频。暂停、静音或离场时回落至 8% 的静态基线。无可用采集时变暗，并在工具提示中说明。连续暂停／停止超过 10 秒平滑收回普通胶囊，恢复后自然展开。

### 音乐控制与能力限制

- 上一首、播放/暂停、下一首分别以播放器 SMTC 广告的能力决定是否出现。命令发送期间，已显示按钮暂时禁用并降至 30% 不透明度，避免重复操作。
- 命令返回成功后还检查播放状态、歌曲元数据或播放位置是否变化；约 2 秒内未确认、返回失败或抛出异常时，记录当前来源、歌曲和动作的失败，并在后续状态刷新中隐藏相应按钮。切歌后可按新歌曲能力重新评估，不保证所有播放器均可控制。
- 控制按钮尺寸为上一首/下一首 40 × 30、播放/暂停 44 × 30，图标为 12–15 DIP；模板必须有非空的透明背景以接受整块鼠标输入。悬停深灰，鼠标聚焦无边框，键盘导航通过 AdornerDecorator 与 FocusVisualStyle 显示白色焦点框。提供中文自动化名称和工具提示。
- 展开区的进度条用于显示，没有拖动跳转行为。播放器未提供时间轴时隐藏进度、时间与同步歌词。歌词来自当前歌曲绑定的 LRC；紧凑态第二行显示当前歌词，展开态单独显示。无歌词时回退，切歌清空。播放模式入口位于控制组右侧，仅在状态和能力均可读时显示并读回确认；收藏不具备可靠接口，保持隐藏。

### 设置控件

两项开关分别控制常驻和隐藏 Windows 系统通知横幅；修改自动保存并立即生效。开关为 46 × 26、圆角 13，白色圆点为 18；键盘焦点显示深蓝边框。停驻时间输入框为 62 × 32，支持小数；无效输入显示红色说明与边框，保留当前有效设置，失焦时恢复有效值。

歌词按钮使用原生 WPF 按钮。当前歌曲就绪且具备时间轴时可载入歌词；歌曲就绪时可清除歌词。说明文字随音乐和时间轴能力变化。

## Do's and Don'ts

- **Do** 保留黑色顶部胶囊、白灰文字、浅蓝播放状态条和原生浅色设置窗口的现有身份。
- **Do** 以实际 WPF DIP、当前动画值和显示器 DPI 校核尺寸；形变期间同步更新裁剪轮廓。
- **Do** 保持通知在上、音乐在下，并依据真实媒体能力、时间轴和动作确认展示内容与控制。
- **Don't** 为不存在的媒体能力显示可点击按钮，或使用模拟波形冒充真实音频。
- **Don't** 将 ColorOS 16 的过渡参考扩展为主题替换、网页布局或新的视觉架构。
- **Don't** 把网页 CSS 规则或检测器结果作为这个原生 WPF 界面的实现依据。
