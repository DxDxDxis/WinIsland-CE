# 1.3.1alpha 文件中转与显示开关

基准是 `../1.3.0-path-state-fix`，BuildId `1.3.0-path-state-fix-20260916`。本版 BuildId `1.3.1alpha-settings-adjust-20260917`。源码、构建和测试均在独立 1.3.1alpha 目录进行。

## 使用

- 音乐歌词 → **在灵动岛显示音乐**：默认开启。关闭音乐卡片与歌词呈现，不控制播放器；重新开启按真实播放状态恢复。
- 界面通知 → **在灵动岛显示消息**：默认开启。关闭退出当前消息并清空等待队列，不补播过期消息。与隐藏 Windows 自带通知独立。
- 其他设置 → **文件中转**：从按钮覆盖当前设置窗口内容，沿用 600 ms 非线性转场。返回保留原设置页布局、滚动、草稿和焦点。快速反向只有一个有效动画，减少动态效果时即时完成。
- **启用文件中转**首次默认关闭；仅开启后接收灵动岛拖入并显示中转组件。关闭停止组件输入、收回组件，保留数据；主设置窗口中的文件管理仍可使用。

导入普通文件后选择“仅作为中转”或“保存并中转”。前者只记录原位置，后者后台复制到数据目录，两者都不移动源文件。首次不会自动复制，可点击“记住此选择”按钮并随时清除。相同有效来源去重，同名不同来源采用不同 GUID，互不覆盖。

复制有排队、进度、取消、失败状态。大小和 SHA-256 校验通过、完整副本发布且索引写入后才显示“已保存”。失效来源可以重新定位。移除默认只移除记录，保留源文件和保存副本；本版没有自动清理保存副本的命令。

主列表宽屏两列、窄屏一列，卡片长名称换行并提供完整名称。按名称或扩展名搜索，组合输入结束后筛选，原 DOM 及选择状态保留；使用稳定 ID 和保留节点，搜索不重建资源。

导入区只有一个模式开关：关闭“仅中转”，开启“保存并中转”。点击确认后生效；“记住此选择”是独立按钮。

卡片点击摘要后，详情在同一条目内以 451.389 ms 线性高度动画展开（收起仍为 650 ms）。快速反向从当前高度续接，操作区域不会误触收起；键盘和减少动态效果均保留。已移除图片、TXT、Markdown 内容预览及其 preload/main 接口和解码 worker。详情只展示文件元数据和已有操作，不读取或执行文件内容。

“侧边吸附后自动展开”默认关闭，单独保存为索引 preferences.sideAutoExpand；开启后每次有效拖动吸附只展开一次。

## 灵动岛与原生组件

文件接收临时优先于音乐、消息，不修改用户显示开关。悬停目标为实际 DPI/缩放下待机宽高的 200%；释放后 300%，受显示器工作区限制。名称区域可滚轮查看，未确认时显示待选择，提供仅中转/保存/取消及 Tab、Enter、Space、Esc 操作。离开或结束后重新判断真实音乐状态，过期消息不补播。

组件由 C++ 主进程管理，无额外常驻服务。收起宽度约待机宽度的三分之一，最小 124 DIP；从主岛滑出到屏内停靠点。顶部点击或连续悬停 3 秒展开，离开、拖动、菜单和拖出取消悬停计时。卡片与标题具有独立操作区域。

长按标题至少 250 ms 并越过移动阈值后移动组件；吸附进入 44 DIP / 退出 72 DIP，顶部/左右之外为浮动视图。左右收起为 46×148 DIP 的竖向岛，文字保持正向；展开向屏幕内部。标题右键还可选择停靠位置。形态动画使用 433.333 ms 平滑非线性曲线；减少动态效果时缩短。窗口位置和目标始终限制在显示器工作区，DPI/显示器变化重新计算。

贴合外形复用主灵动岛的 `islandOutline` 曲线和当前外扩圆弧参数，背景纯黑；顶部贴合工作区上边缘，左右只转换轮廓方向，文字不旋转。轮廓与窗口尺寸同步过渡，裁剪和命中使用同一形状。中转通过 Direct2D/DirectWrite 在预乘 Alpha 表面绘制，再透明合成；显示轮廓不再由整数窗口区域裁切。不同显卡/DPI 的动画观感仍需实机验收。

展开列表只绘制可见卡片，限制高度。底部“显示更多文件”扩展同一个窗口，优先向左并避开屏幕边界，再次点击返回紧凑面板，保留搜索/滚动。更多/浮动窗口默认 460×420 DIP，最小 360×300 DIP，可拖动边框或角落调整大小。完整的更多按钮作为动画起点；返回快照独立保存模式、锚点、位置、尺寸和滚动。浮动模式底部“紧凑”在原位置收起。原生窗口直接键入搜索，Backspace 清除、上下选择、Enter 打开条目详情；主界面提供完整表单搜索。

长按文件卡片至少 350 ms 并移动超过阈值进行拖出。宿主使用 IDataObject / CF_HDROP / IDropSource / DoDragDrop，只允许 DROPEFFECT_COPY。仅中转使用原文件，保存条目使用副本；接收方可拒绝。Esc 取消不改变源文件。右键菜单提供移除记录、打开原位置、打开保存位置。

## 数据和恢复

继续使用已有固定定位记录和首次安装确认的 dataDir()，不跟随 EXE 移动。

```text
<dataRoot>/settings.xml                   ShowMusic / ShowMessages
<dataRoot>/file-transfer/index.json       version 1
<dataRoot>/file-transfer/index.backup.json 上一份有效索引
<dataRoot>/file-transfer/files/<GUID>/<原名称>
<dataRoot>/file-transfer/staging/<GUID>.partial
<dataRoot>/file-transfer/previews/        历史预留目录；修复版不再创建或使用，已有目录保留
<dataRoot>/electron-data/                 已有 Electron/Chromium 数据
<dataRoot>/logs/                          已有日志目录
<dataRoot>/mods/                          原插件包、状态和设置
```

索引保存稳定 ID、文件名、后缀、大小、导入时间、原位置、可选副本、模式、状态、错误，以及启用、记住模式、停靠坐标。进度在内存发布，状态变化原子落盘。复制先写 staging，校验后发布完整副本，再提交索引。

重启将 queued/copying 标为取消并检查 ready 文件可用性，不自动继续大规模复制或删除源文件。残留 staging 和未被索引引用的副本保留。主索引损坏尝试备份，两份都损坏则停止写入、显示错误，不用空索引覆盖。相同根目录只有一个进程取得中转所有权，第二实例明确说明不可写原因。数据盘离线会返回错误，不切到 EXE 同级另建数据。

应用自身持久化文件由统一根目录管理。Windows Shell 缩略图缓存、资源管理器历史和系统诊断属于系统管理，不能宣称应用控制所有系统文件。

## 开发接口和生命周期

`TransferPage → 隔离 preload → Electron main 白名单 → token 命名管道 → App → TransferStore`。原生组件直接使用同一 TransferStore。自身 OLE 数据对象携带进程实例 GUID，返回宿主区域不导入、不触发外部接收；拖放会话结束后统一清理。副本有独立工作队列，普通文件检查使用后台任务。隐藏组件不持续逐帧绘制，仅动画或悬停计时时开原生定时器；OLE 模态循环期间驱动主岛 tick，避免只有鼠标移动才刷新。

新增 transfer.call 动作：list、enable、side-auto、import、choose、cancel、remove、relink、location、refresh、forget、preferences、resolve、drag。renderer 通用 call 不开放任意路径 import、resolve、drag、preferences；选文件由 main 对话框注入路径，拖入由 preload webUtils.getPathForFile 提取。详情/拖出只传 ID，由宿主解析。批量导入/确认按 IPC 大小分批。

contextIsolation=true、nodeIntegration=false、sandbox=true 保持不变，无外部导航和新窗口权限。ShowMusic/ShowMessages 继续遵循 revision、成功保存后确认的设置协议。产品版本升级未改变插件 POD 生命周期 ABI 0x00010002，场景、渲染、媒体、设置表均保持 version 1。QuickJS、GSAP、插件动画运行时保留。

退出先结束 IPC/任务，再撤销 DropTarget、释放 COM 对象并销毁组件。运行时取消复制由任务标志处理，异常退出后的未完成记录只能恢复为非成功状态。

## 构建和回退

构建：`./build-release.ps1 -BuildTools E:\WinIslandBuildTools`。先构建/打包 Electron，再内嵌运行组件并生成 `release/WinIsland-1.3.1alpha.exe`，不要直接运行设置子 EXE。

隔离运行：`WinIsland-1.3.1alpha.exe --verify <本工程 verification 下的独立目录>`，不改日常定位记录/开机启动。诊断 command.txt 支持 transfer-enter/drop/leave 等状态集成验证，它们不代表真实资源管理器跨进程拖动已通过。settings-connection.json 含短期凭据，不随发行包分发。

回退前退出新主程序并备份数据根目录，启动保留的 1.3.0 修复版。旧版不识别中转目录；不要手动删除该目录。旧版重写 settings.xml 可能不保留新增两个字段，再升级时可能使用默认开启值；中转索引独立保留。基准 SHA 清单及复核结果在 verification。

实际验证和未覆盖环境见 [验证报告](1.3.1alpha验证报告.md)。

当前专项修复验证见 [文件中转专项修复报告](1.3.1alpha文件中转专项修复报告.md)，旧报告中的预览行为仅为历史记录。

当前吸附、120% 动画速度、圆角与 10 秒自动收回规则见 [本轮优化报告](1.3.1alpha文件中转吸附与动画优化报告.md)。只有停靠展开面板适用自动收回；操作重置，拖放/菜单/输入法/关联文件选择暂停，浮动和更多完整视图不适用。

## 2026-09-17 设置布局修订

其他设置底部两个等大入口依次为“插件管理”“文件中转”。页面使用按钮实时边界展开到当前窗口完整客户端区域，操作系统标题栏保留；返回恢复原滚动和焦点。页面进入/退出仍为 600 ms。

“降低动画”是手动开关，默认关闭，保存到数据根目录 `settings.xml` 的 `ManualReducedMotion`。旧自动模式没有手动记录时按关闭处理；系统减少动态效果不再覆盖用户选择。开启后导航保留选中高亮但立即定位，下拉开合不播放过渡；不会暂停播放器、视频或文件复制。

接收状态直接复用主岛背景颜色和透明度，不再绘制灰色底板，也不叠加按压白色反馈。详细验证与回退见 [设置修复报告](1.3.1alpha设置布局与手动动画修复报告.md)。
