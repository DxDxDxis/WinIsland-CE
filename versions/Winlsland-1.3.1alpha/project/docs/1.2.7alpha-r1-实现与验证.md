## 实际根因与实现

旧插件生命周期能正常启动，但静态资源路径没有动态图像帧调度和 H.264 解码器，只有 load/bind 类名不能产生动态播放。r1 增加 MediaEngine 解码 worker、MediaApi C 表和 media_host 桥；WIC 将 GIF 帧按延时/disposal合成，MF SourceReader 输出 H.264 BGRA，宿主单调时钟控制 pause/seek/loop/rate。节点保留宿主帧，D2D同尺寸bitmap复用。owner/generation令旧换源和卸载结果不能覆盖新节点。

根背景原来存在底板覆盖透明度的路径，已改成有效根背景只绘制一次。拖动新增 start/update/end/cancel 与宿主捕获清理。scene.commit逐帧日志已移除，样例暂停后状态不变不再commit。只作用于本版副本。

## 未完成验收与实现限制

- 未验收：真实多显示器/跨屏DPI、物理鼠标越窗capture/触摸/键盘整条链、休眠恢复、强制设备丢失、长时间内存/GPU资源增长、4K/高码率、低内存、多声卡、无音频设备、Windows N/KN。
- 未验收：本地选择文件确认成功路径、插件配置重启/升级迁移、真实第三方音乐/歌词/通知全部业务、Electron全部操作与托盘；不将合成音乐回归替代真实来源验收。
- 未实现：WebP/APNG/动态WebP/SVG/AVIF、非H.264 codec、硬件视频解码、透明视频、网络媒体、无DLL纯JSON皮肤、EXIF方向/ICC、透明像素命中、完整IME。
- 根scale/rotation/shadow仍UNSUPPORTED；子节点变换已实现。根尺寸/位置/背景/圆角/边框和原生替换能力已连接；不宣称任意整窗旋转。
- 音频默认静音，PCM输出已测；严格A/V同步、所有倍率的听感和设备兼容未验证。事件是最新状态通知，快速中间状态可合并。单decoder worker不能强制打断某个系统codec调用。
- 同进程DLL不能隔离任意崩溃、死循环或非法内存写；仅通过正式API的owner贡献可以可靠撤销。
