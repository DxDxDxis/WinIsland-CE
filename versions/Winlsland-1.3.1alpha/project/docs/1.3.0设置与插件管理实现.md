# WinIsland 1.3.0 社区版：设置与插件管理

## 基准与范围

基准为 `release/1.2.7alpha-r1`，BuildId `1.2.7alpha-r1-dynamic-media-20260914`。基准根 EXE、release EXE 与构建清单记录一致：SHA-256 `C989EA32C2413428C09713D84511AC0DC964129010CA83E8FC84101EF1904BEC`。检查时日常运行进程也来自这个目录。

所有产品修改、构建和验证在独立 `release/1.3.0` 中。复制范围含 source、settings-electron、已打包 Electron 运行时 settings、lyric-provider、SDK、插件测试资源、文档和构建脚本；不复制用户日常 mods。旧目录的 775 项源码、发布文件、依赖和资源哈希记录在 `verification/r1-baseline-sha256.json`，最终比对见验收报告。

正式设置入口是 `App::openSettings → settings/WinIslandSettings.exe`。`mod_ui.cpp` 是保留的原生诊断界面；此次新卡片、搜索和动画均属于 Electron 正式界面。沿用实际源码中的五个分类，不改名、不新增分类。

产品版本是 `1.3.0`，显示为 **1.3.0 社区版**；BuildId 为 `1.3.0-community-settings-20260916`。生命周期 ABI 仍为 `0x00010002`，场景、设置和媒体接口版本保持不变。XML 内旧格式标记不作为产品显示版本升级，不重写用户配置格式。

## 修复依据

旧 renderer 的 `renderPlugins` 对每次模组/资源变化执行 `replaceChildren`，创建完整大卡片与所有设置控件。该结构没有独立展开状态，容易让轮询刷新丢失焦点和草稿。旧 `mods.list` 把 API 版本合成为 `valid ? 1 : 0`，且未发送入口 DLL、依赖版本约束、设置 key。旧导航只有普通缓动的位移/缩放，无速度延续；插件页面瞬时替换。

新实现保持原有浅色背景、蓝色选中底板、白色圆角卡片、字体和原生语义控件，不引入新动画运行时。

## 卡片和搜索

`settings-electron/src/plugins.ts` 的 `PluginList` 按稳定模组 ID 保有 `ModCard`，状态轮询只更新对应文本、状态与资源，不重建列表。移除已不在快照中的 ID 时释放该卡片的 ResizeObserver 和动画。

收起卡片是 54 CSS px 的摘要按钮（含边框外高 56 px），三列只显示名称、作者、版本。名称、作者和版本均单行省略，title 可查看全文；展开详情始终包含完整名称。缺省作者与版本统一为“作者未填写”“版本未填写”。原生 button 支持 Enter、Space、Tab、焦点提示和 aria-expanded。详情按钮、文本选取、表单和滚动不会触发收起。

展开 ID 集合保存在 Electron localStorage 的 `mods-expanded`；搜索和筛选只设置 hidden/inert，不请求宿主操作。中文组合输入开始后暂缓更新查询，compositionend 才应用查询。匹配名称、忽略大小写。按 ID 保留节点避免串位，使用真实滚动容器的滚动位置与自然边界夹紧，不在搜索或状态刷新时调用 scrollTo(0)。详情内状态变化或窗口换行触发的重新测量限定到该张卡片。

## 元数据和真实操作

`settings_host.inc` 在原协议 1 的 `mods.list` 响应中追加 `entry`、`gameVersion`、`packageHash`、`hostAbi`、`actualAbi`、`dependencyDetails` 和资源 `key`。保留旧字段；未改变 main/preload 的权限、令牌或命令边界。`apiVersion` 改为真实解析值，读取失败用 0 表示未知，不能把校验失败当作 API 0。

可解析但不兼容的包保留清单信息供显示；仍必须通过 validate 才可安装或执行。签名分别显示未知、未签名、签名有效（Windows 信任链）、签名无效。入口 DLL、包文件和清单 API 分开显示。依赖结果由宿主的同一个版本匹配器计算，区分未安装、依赖无效、版本不符和满足；DLL ABI 只有实际加载读取过才显示结果。

| UI 操作 | 实际路径 |
|---|---|
| 添加模组 | main 文件选择 → mods.import → ModLoader::install → 包校验、原子写包、scan；默认禁用 |
| 启用/禁用/卸载 | mods.action → 工作线程 enable/disable；回调门、资源撤销、DLL 生命周期沿用现有实现 |
| 批量重载 | mods.action(reload) → 依赖顺序关闭、scan、恢复原运行集合 |
| 日志与错误详情 | mods.log → 当前模组日志，最多 256 KB，加当前错误摘要；在卡片内显示 |
| 模组设置 | WI_SETTING/WI_BUTTON 资源 → mods.invoke → 工作线程验证、持久化、回调或正式接口读取 |
| 重装 | mods.action(reinstall)，见下一节 |

UI 一次只提交一个宿主操作，禁用不可用按钮；等待 operation/completedOperation/operationError 确认结果，不能将排队视作成功。失效资源、未启用资源和回调异常返回真实错误。修正了批量影响范围只返回空 ID 的旧问题。

## 重装语义与失败恢复

重装是**用当前已安装的原 .wimod 修复提取文件并重建实例**，不是选另一版本的文件。确认框展示完整来源、依赖影响、数据保留及恢复语义。

1. 从已知 packageFile 读取原包，验证路径、ZIP、CRC、签名、清单及 ID/哈希；包变化要求用户先刷新并核对。
2. 当前缓存与已加载 DLL 不被覆盖；先完整提取到 `mod-cache/repairs/<ID>/<PID>-<tick>/...` 新目录。
3. 记录相关插件的 desired 和已启用集合，按依赖顺序关闭。
4. 当前目标绑定新缓存，恢复原启用集合；原来禁用/卸载的目标不擅自启用。
5. 启动失败则绑定回旧包和旧缓存，尝试恢复原启用集合，返回失败；原实例也失败时明确报告，不伪称回滚成功。

包、设置、日志和旧缓存都保留。旧修复缓存暂不自动清理，连续重装会占用额外磁盘；重启时常规哈希缓存仍按原包内容校验/修复。此实现不提供替换为另一包版本的“升级重装”，导入重复 ID 仍拒绝覆盖。卸载继续沿用原宿主“停止并撤销实例，保留文件”的语义。

## 模组设置

从当前 SDK 的 WI_SETTING / WI_BUTTON 读取：稳定身份是 owner + kind + key，handle 是当前会话资源句柄，重载后重新绑定。typed 设置支持文本、数值（min/max）、开关、选择项。旧 WI_SETTING 的未指定类型仍按文本处理。SDK 当前没有 description 字段，UI 不伪造开发者说明，而显示标签、范围和设置键。

文本、数字、选择项显式保存，开关成功前保留宿主确认值。工作线程保存 XML 成功后再公布资源值；持久化失败恢复内存值；回调失败停用并显示错误。旧资源回调得到保存值；typed 设置通过既有 `WiSettingsApi.read` / `getSetting` 同步读取，不新增虚假通知 ABI。测试模组以原定时器正式读取接口，日志证明四类值已被插件观察到。

同卡片“日志与错误详情”和“模组设置”切换保留真实表单 DOM。脏输入不被轮询覆盖，重载后同 key 重新绑定句柄；禁用后明确显示资源不可用并保留脏输入。未注册任何选项且确实启用时才显示“该模组未提供可配置选项”。窗口关闭未保存草稿不落盘；已经保存的数据由 C++ 原设置存储恢复。

## 动画与页面归属

参数集中于 style.css 的 `--motion-nav:325`（旧 260 × 1.25）、`--motion-card:480`、`--motion-expand:540`，单位 ms；共用非线性 `--motion-ease`。`motion.ts` 使用浏览器同一单调时钟；不新增 Electron 动画框架。

- 导航背景：单个 1×1 底板用 transform 定位和伸缩；阻尼比 0.79，角频率由 325ms 基准计算。解析积分保留位移和速度，快速反向只替换目标。动态拉伸不超过目标宽度约 16%，绘制越界限制 6px，文字和点击区域完全不变。独立 indicator-viewport 提供溢出空间。静止后停止 rAF，移除 will-change。
- 卡片：一次读取当前实际高度及真实内容高度，WAAPI 插值该卡片 height，让后续卡片随布局移动；正文只做微小平移/透明度，不缩放文字。快速反转读取当前高度后取消旧动画。结束恢复 auto，适应换行、设置区切换与 DPI；没有固定详情高度。
- 插件页：settings → opening → plugins → closing → settings。入口真实 DOMRect 是起点，宿主滚动区域是终点；一个固定视觉表面用 transform 扩展，文字用 opacity/clip-path 显示，文字不缩放。返回的 inert 静态副本只用于短暂退出画面，无 ID、输入能力或事件回调。真实页面互斥挂载，过渡双方 inert；结束才转交焦点。Escape 可在打开中返回，在返回中反向打开。尺寸变化重新测量并从当前视觉矩形接续；代次废弃旧完成回调。不修改窗口尺寸。
- 其余普通分类内容即时切换，没有重新启用旧的内容左右滑动/淡化。原有开关与原生语义下拉的样式和保存路径继续保留。
- prefers-reduced-motion 即时到达终态，清理待完成动画。beforeunload 取消 rAF/WAAPI、释放 observer、清除轮询及 IPC 等待。

QuickJS/GSAP、C++ 灵动岛动画和插件动画接口保持原样，不能用 capabilities.settingsAnimation=false 推断 Electron 是否有视觉动画。

## 构建与回退

在 1.3.0 目录执行 `./build-release.ps1 -BuildTools E:\WinIslandBuildTools`。脚本始终重建 renderer；不会把基准 ASAR 当成新产品。Electron 44.3.0 运行时来自已记录哈希的副本，package.cjs 去掉旧应用资源后重打包，写入新的 ASAR 和 1.3.0 版本资源；无需再次下载 Chromium。npm 精确版本由锁文件控制，缓存位于 1.3.0/dependency-cache。

启动 `release/WinIsland-1.3.0.exe`，保留同级 settings 目录。歌词组件继续内嵌主 EXE。正常模式保留原有单实例行为：运行旧版本时，新 EXE 会唤起现有实例；正式切换版本应先从旧版本托盘正常退出。本次验证使用 `--verify` 独立目录，不停止日常实例，不写日常配置或插件目录。

回退：关闭新版本，重新运行原 r1 EXE。插件 ABI 和配置格式不迁移，不覆盖旧文件。显式声明 `gameVersion <1.3.0` 的插件将按作者约束拒绝加载，即使 ABI 一样；不要删除该约束或声称它自动兼容。此次媒体回归使用仅调整测试包版本范围的独立副本，DLL 本身保持原字节。

验证命令和实测结果见《1.3.0验收报告》。源码与构建产物的关系由 build-manifest.json 和 SHA-256 清单记录。
