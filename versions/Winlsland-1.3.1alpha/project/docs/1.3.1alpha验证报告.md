## 已实现行为与约束

- 音乐/消息开关只决定宿主呈现；接收文件的临时隐藏不改变用户开关，不补播过期消息。
- 主页面转场复用既有 600 ms 非线性 morph；覆盖当前设置客户区，底层原页面保留并暂时 inert。原生组件阻尼几何动画 560 ms；侧边阶段采用线性进度；缩回 400 ms。减少动态效果走短动画或即时终态。
- `<dataRoot>/file-transfer/` 管理 index、files、staging 和预留 previews。首次关闭，无记住模式时必须确认后才复制。复制完成并校验后才发布“已保存”。不同来源同名按 GUID 分开，默认不移动/删除源文件。
- queued/copying 重启标记取消；失效来源提示重新定位；主索引损坏回退备份，均损坏则拒绝写入。一个根目录只允许一个中转所有者。
- 主页面和原生视图共用 TransferStore；原生窗口预览入口打开已有 Electron 中转页，不创建另一套数据。OLE 仅允许 COPY，目标应用可以拒绝。

## 未完成验收与已知限制

1. **未验证资源管理器/桌面真实拖入和拖出**，因此真实目标是否接收且源文件保持的最终验收未完成。已实现 CF_HDROP/DoDragDrop COPY，不宣称所有应用可接收。
2. 真实标题长按移动、连续边缘吸附、3 秒指针悬停与快速反向的完整人工验收尚未完成；仅窗口过程测试和有限桌面观察通过。工具默认短拖动未达到长按阈值。
3. 多显示器、外接屏断开、真实 100%/125%/150%/200% DPI、不同刷新率未实机完整验证；已实现工作区约束和 DPI/显示器变化处理。
4. 未制造物理拔盘、真实磁盘写满、ACL 拒绝和断电；覆盖了无效来源、模拟不可用根目录/空间不足、复制取消、强制退出和索引损坏。未进行所有播放器、通知应用的端到端回归。
5. 图片方向由 Windows 缩略图服务处理，EXIF 方向专项未验证；图片 >50 MB 不快速预览，动图为静态帧。文本最多 512 KiB；Markdown 展示安全源码，不渲染富文本。
6. 原生浮动/侧边视图为自绘轻量搜索（直接键入），没有独立可编辑搜索框；完整搜索表单和预览在设置中转页。真实中文 IME 输入尚未验收。
7. 移除记录保留保存副本；本版未提供自动孤立副本清理和复制断点续传。staging 残留保留供恢复，不自动删除。
8. 未完成长时间 CPU/内存、动画帧率和海量文件压力测量，不能宣称零性能损耗或全部动画验收通过。
