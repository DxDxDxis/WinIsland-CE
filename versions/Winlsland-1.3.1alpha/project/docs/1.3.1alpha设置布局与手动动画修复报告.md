# 1.3.1alpha 设置布局与手动动画修复

本次只修改 `E:\aaAAx项目\WinIsland-社区版-大更新\release\1.3.1alpha`。实际基于构建 `1.3.1alpha-transfer-polish-20260917`，新构建为 `1.3.1alpha-settings-adjust-20260917`，产品版本仍为 1.3.1alpha。插件 ABI 和 IPC 协议版本不变。

## 已完成的修改及原因

| 修改位置 | 实际原因与修复 |
|---|---|
| `source/src/render.cpp` | 接收状态在正常底板之上另绘制不透明 `#181A20`，所以悬停、释放时变灰。现在只使用原有根节点的 `modTint`、可见性、背景透明度与根透明度。临时裁掉音乐、通知等前景绘制，保留它们的宿主场景元数据；绘制接收内容前恢复裁剪。没有用重复黑色填充破坏透明度。 |
| `source/src/app.cpp` | 接收时清理按压反馈，渲染端也禁止接收状态叠加白色按压罩，避免过渡期间发灰。`applySettings` 读取明确手动设置，不再读取系统动画策略。 |
| `settings-electron/src/renderer.ts`、`style.css`、`transfer.ts` | 原按钮分别约 164×54.58、400×56 CSS 像素，纵向排列。现在共用 `page-entry` 和一行容器，正常宽度均为 164×54.58、间距 12，插件管理在左、中转在右；窄区域换行。按钮保留真实进入命令、焦点和相同交互样式。 |
| `settings-electron/src/motion.ts` | 插件管理原来以 `#content` 为目标，仅覆盖工作区。现在插件与中转都覆盖 `(0,0,clientWidth,clientHeight)`，保留 Windows 标题栏、移动及关闭。每次进入、返回、窗口 resize 都读取实时入口边界；返回前准备原滚动位置。起终圆角同步，避免最后一帧改变边缘。 |
| `source/src/core.h/.cpp`、`settings_host.inc`、`protocol.ts` | 原“降低动画”只是系统状态说明，没有持久化手动字段。新增 `reduceMotion` / XML `ManualReducedMotion`，默认 false，沿用 revision 校验和原子保存。只有保存成功后才确认控件状态；失败显示错误并恢复核心实际值。 |
| `motion.ts`、`style.css`、`transfer.ts`、`index.html` | 统一采用核心确认的手动偏好，移除系统媒体查询监听和 CSS 自动降级。开启后取消正在运行的导航、详情和页面转场并落实最后目标；下拉直接开合，导航高亮保留。关闭后恢复正常动画。页脚同步为手动控制说明。 |

下层设置页始终保留，过渡中使用 inert 禁止输入，覆盖层完成后不会穿透点击。返回时解除 inert 并恢复焦点。视频、动图、音乐播放、复制任务和业务计时不由此开关停止。

旧自动状态不存在可恢复的手动选择，不据此推断开启。缺少 `ManualReducedMotion` 时关闭；明确保存的 true/false 重启保留。旧版可以忽略新增 XML 字段。
