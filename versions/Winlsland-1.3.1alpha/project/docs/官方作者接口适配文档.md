# 官方作者接口适配文档 — 1.2.7alpha-r1

本文是实现契约，准确函数与POD见SDK接口参考.md；媒体逐函数语义见媒体资源与皮肤扩展.md；原生元素属性见开放场景API.md。

## 最小宿主契约

1. x64 C函数表生命周期0x00010002，size/version与UTF-8；工厂/销毁由DLL自身CRT管理。保留旧HostApi前缀。
2. queryInterface发现scene/settings/media扩展。缺失返回UNSUPPORTED；media ABI1支持较短旧表和旧info容量，不越界拷贝。不得以产品版本号机械替换ABI。
3. owner只能从宿主context取得；所有元素、属性层、输入、timer、媒体、异步结果均可追到owner；不可接受插件伪造owner。
4. 场景暂存到commit才发布；宿主实时baseline与每个owner覆盖链分开，撤销重算剩余层。
5. worker串行执行插件callback；渲染只读宿主复制数据。解码放独立worker，UI不等待文件或codec。
6. 媒体异步LOADING/READY/PLAYING/PAUSED/STOPPED/ENDED/ERROR；受理成功不代表播放成功。换源generation、过期回调拒绝、预算、取消必须生效。
7. 输入在最终DIP/父子逆矩阵中命中，host capture/focus与revoke清理一致。不得把拖进度条变成拖窗口。
8. 停用停止新请求、移除回调/节点/属性层、取消媒体、发布撤销，再destroy/FreeLibrary；GPU和解码帧不可保留DLL指针。

## 可替换实现

MediaEngine可用官方实现替换WIC/MF/waveOut，但能力位必须与实际格式/音轨/硬件路径一致。Renderer可换官方渲染后端，必须保持straight RGBA属性、PBGRA像素、同一布局命中、fit/crop与帧所有权。官方设置UI可自行实现typed settings，不需依赖社区版Electron。仍保护系统设置框架、安装器、托盘、权限、加载器。

可以开放所有已连接的通用元素/布局/媒体控制，不创建addTimeLabel等专用入口。r1根size/position/background/radius/border可用，根scale/rotation/shadow未实现必须返回UNSUPPORTED；子节点变换可用。原生内容只在真实存在时提供key；不存在返回NOT_FOUND。

## 兼容和验收

旧插件不查询media仍可运行。旧版未知扩展走非媒体降级。大wimod可能被旧包上限拒绝；新媒体插件应明确最低宿主。不得把同进程DLL异常保护宣称沙箱，不能保证内存破坏恢复。

移植至少运行：较小media表/info哨兵、错误线程/owner、GIF oracle、H.264连续帧与暂停seek、音轨错误、快速换源/释放、两个owner停用A后B继续、原生内容替换恢复、DPI变换命中、退出时在途任务。社区版已测/未测清单见报告，不能把其测试结果直接复制为官方移植已通过。
