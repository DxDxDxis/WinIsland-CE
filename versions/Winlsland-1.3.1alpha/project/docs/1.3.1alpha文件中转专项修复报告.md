## 主灵动岛贴合外形追加要求

原组件的普通 RoundRect 已替换为主岛 `outline.h/islandOutline()` 的同一组贝塞尔曲线：贴边一侧使用外扩肩弧，内侧使用胶囊圆角，背景纯黑且不绘制独立灰色外框。App 将当前 TopArcScale 与缩放计算出的外扩参数传给中转组件；主岛渲染代码与参数算法未改动。

顶部使用原方向；左右侧只对轮廓作坐标变换，文字保持正向显示“文件中转”。绘制与窗口裁剪/命中区域共用同一轮廓。沿用主程序的显示器 **rcWork** 边界规则；若任务栏占据某侧，该侧贴合可用工作区，不覆盖任务栏。

`transfer_outline.h` 组合贴边权重，方向、肩弧、圆角与窗口矩形共用一个 520 ms 时钟。反向操作保留当前形状和位置进度；更多入口小按钮的 7 DIP 圆角也随展开连续过渡。不会旋转或拉伸文字。

四档 DPI 的曲线数值一致性测试通过；离屏真实绘制结果见 [贴合轮廓](../verification/transfer-fix-contours.png)。这张图是诊断绘制拼图，**不是桌面截图**。主岛使用 Direct2D，中转保留现有 GDI/窗口区域路径，尚未证明不同显卡和缩放下抗锯齿像素完全相同，不能宣称逐像素验收完成。

## 参数与状态规则

- 文件条目：650 ms **线性**高度展开，按剩余距离缩短反向时长；当前 clip 高度作为起点，仅测量对应详情；文字不缩放。关闭详情 inert，事件与操作节点保持稳定，销毁时取消动画和 ResizeObserver。
- 原生形态：520 ms `t²(3−2t)`，使用实际时间；减少动态效果时 10 ms 达到终态。轮廓与矩形同步插值。
- 侧边紧凑：46×148 DIP；顶部横向、最小宽 124 DIP。标题手势区域与文件卡片分离。
- 更多/浮动：默认 460×420 DIP，最小 360×300 DIP；调整后保存 moreWidth/moreHeight。显示器工作区更小时受其限制。
- 吸附：44/72 DIP 进入/退出阈值，停靠位置在鼠标释放后连续吸附。侧自动展开只在这次有效释放处理；轮询和列表更新不会重复触发。
- 每次更多展开保存 ReturnState；返回使用该快照。主动拖动撤销旧来源，用新的位置锚点；浮动的紧凑操作始终在当前位置收回。More 的标题/返回返回真实存在的面板。
- 新增/移除/复制仍走同一个 TransferStore、原索引和统一数据根目录。旧 previews 目录不再创建或使用，但不擅自删除用户已有文件。
- 自身拖出为 COPY-only OLE 会话；返回自身不重新导入、不改变原记录或原文件。Electron 视图的导入入口在宿主 outgoing 会话期间同样拒绝重复导入。
