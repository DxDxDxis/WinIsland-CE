# 1.2.3beta 原生 C++ 迁移核对清单

基准：1.2.2beta C# / .NET Framework / WPF；保留原发布文件和 `%LOCALAPPDATA%/WinIsland` 配置、歌词文件。

| 模块 | 原有实际行为 | 原生迁移目标 | 验证 |
|---|---|---|---|
| 主窗口 | 主屏顶部 8 DIP，待机 180.4×29.92，紧凑音乐 460.46×48.384，展开高 105/121.8，宽上限 616 | Win32 + DirectComposition/Direct2D/DirectWrite，同一黑色圆角外壳，DPI 响应 | 已通过本机几何与渲染比例检查；真实多屏未测 |
| 动画 | 0.56 秒音乐舒展、0.42 秒展开、0.52 秒通知；单调阻尼；打断后从当前位置续接 | 一套几何状态和渲染调度，GPU 优先、软件回退 | 硬件/软件测试通过；实测 FPS 另见报告 |
| 交互 | 点击音乐展开，上一首/暂停播放/下一首，能力不足隐藏；键盘焦点 | 原生命中与键盘操作，控制绑定当前来源和歌曲，异步确认 | 真实 SMTC 测试媒体通过；实际客户端见报告 |
| 音乐 | 网易云、QQ 音乐、汽水 SMTC；稳定选择正在播放来源；退出清理、暂停 10 秒收回 | C++/WinRT 工作线程；有界最新状态信箱 | 网易云部分实测；QQ音乐/汽水未实测 |
| 歌词 | 每首 SHA256 命名 UTF-8 LRC，本地导入/清除；真实时间轴同步，无进度不伪造 | 同一文件格式与哈希，后台解析、测量缓存 | 配置哈希及真实 SMTC 时间轴测试通过 |
| 音频 | 六根进程回环 PCM 音量历史；静音回落，不可用不模拟 | C++ WASAPI 独立工作线程，内存采样不落盘 | 真实测试 PCM 和静音通过；旧 Windows 有限制 |
| 通知 | 只读 Windows 数据库、启动基线、去重、同事件合并、FIFO 不丢；系统横幅可隐藏 | 原生 SQLite/XmlLite 后台读取，数据版本检查，独立恢复辅助进程 | 解析/启动基线/去重/FIFO通过；横幅助手未单独实测 |
| 音乐与消息 | 消息从音乐底部连续延伸，收回不折叠已展开面板 | 同一状态容器，下方内容裁剪，不遮挡控制 | 消息向下、展开保持、反向收回测试通过 |
| 托盘设置 | 常驻、系统横幅、停驻秒数、0 或30–240帧率、导入/清除歌词，立即保存 | Win32 设置界面，读写原 XML，版本 1.2.3beta | 设置保存、边界校验、日志功能通过 |
| 系统生命周期 | 单实例，开机启动注册，退出移除，锁屏/睡眠暂停并恢复 | 同名互斥体/注册表项/WTS/电源事件；任务可取消并释放 | 正常退出通过；睡眠/锁屏/多屏未实测 |
| 能力边界 | 没有真实收藏入口；模式仅有真实 SMTC 读写能力才显示；没有音量滑块或在线歌词 | 保持边界，不加模拟功能 | 与原代码边界一致；没有伪造收藏/歌词 |
| 诊断/发布 | EXE独立运行但依赖系统CLR；已有自动测试 | /MT静态VC运行库，无CLR/WPF；低开销性能日志、原生测试模式 | 原生 PE/静态运行库检查通过；干净系统未测 |

性能基线：`../WinIsland-1.1.2社区版/artifacts/perf-before-1/metrics/`（相对工作目录）。4000 行压力歌词反复展开时，主线程歌词测量平均293.473ms、最大385.690ms，音乐帧间隔最大406.405ms。该压力输入复现了阻塞路径，不代表每台电脑日常歌词均有这一峰值。驱动/多屏/电源对用户日常卡顿的贡献尚未确认。
