本次相对原生优化前 EXE 缩小约 **5.6%**，CPU/秒约下降 **9.0%**，活动回调峰值约下降 **19.9%**；工作集略升约 0.68 MB，不能声称这轮全部资源指标都下降。旧 C# 歌词阻塞得到明确复现；最终原生工作集相对该压力基线减少约 57.9%。C# 单个 EXE 比原生 EXE 更小，因此不能将原生体积优化宣传为比 C# 单文件更小。

最终后台歌词测量约 999.85 ms，仍有 CPU 成本，但只做一次、不占用 UI 布局。这轮未实现 SIMD 或显卡频谱。帧回调指标不等同于显示器真实呈现帧率，没有直接采集 GPU 百分比。未验证用户朋友电脑的驱动/功耗情况。

- PE 依赖：`tests/dependencies-final.txt`、`tests/pe-final.txt`；没有 CLR 描述目录或独立 VC 运行库导入。

发布 ZIP：`WinIsland-1.2.3beta-Windows-x64.zip`，包含 EXE、使用说明及 EXE SHA256 清单。约 **354 KiB**，不含测试工具或日志。源码和构建说明在本目录 `src`、`build.ps1`、`README.md`。解压副本验证位于 `tests/extracted-release`，不依赖源码目录中的 DLL/资源；这仍不是无开发环境的干净系统实测。

解压包的软件完整回归已通过：`tests/software-release/results.json`；解压 EXE 与构建及正式发布 EXE 的 SHA256 相同，12 项自测也通过（`tests/selftest-extracted.txt`）。

持续采样获得 **140.94 秒、29 条资源样本**，活动回调峰值 **51.835 ms**。监测开始工作集 49.258 MB、私有 30.371 MB；结束工作集 66.227 MB、私有 44.945 MB；句柄 1121→1195，GDI 14→19、USER 20→33。期间有 UI 操作和资源建立，不能据此直接判定泄漏，也不能宣称内存完全不增长。

**这轮持续测试未完成预定流程，不计为通过：**应用在 140.94 秒时进入正常退出路径，保存了带结束时间的报告；退出触发源尚未确定，测试脚本随后因命令未被消费而超时。完整数据保存在 `tests/soak-release/monitor-report.txt` 和 `result.json`。多天运行稳定性仍未验证；本次交付的核心功能回归与这项未完成的持续测试应分开看待。
