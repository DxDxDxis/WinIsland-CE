WinIsland 1.2.3beta · 原生 C++ 社区版

运行：解压后双击 WinIsland-1.2.3beta.exe。请先退出旧版，程序使用单实例锁。
目标系统：Windows 10 1809 x64 或更新，建议 Windows 11。
VC/C++ 运行库、图标及版本资源已内置，不需要 .NET、Python、Visual Studio、Qt 或 WebView2。
不需要联网下载运行库；Windows 自带组件仍需完整。

设置：右下角系统托盘 → 设置。原配置和本地歌词继续使用 %LOCALAPPDATA%/WinIsland。
音乐：在播放器内开启 SMTC/系统媒体控制。只显示真实提供且可确认的控制能力。
歌词：为当前歌曲载入本地 LRC；播放器必须提供真实时间轴才能同步。
音量竖条：读取所选进程的真实音频。需要 Windows build 20348+，接口不可用时不模拟。
通知：仅能接收 QQ 等应用实际向 Windows 发布的系统通知；前台会话/免打扰可能没有系统通知。

采集卡顿：设置 → 启动信息监测 → 复现问题 → 停止信息监测 → 导出日志报告。
默认保存：程序旁 daxian日志/daxian日志_年月日_时分秒.txt。
程序目录不可写时改存当前用户“文档/daxian日志”，设置中显示实际路径。
监测中也能导出，不会中断；重新监测前请先导出要保留的上次报告。
正常报告不记录聊天正文、歌名、账号或凭据。

验证边界：本机 Windows 11 上验证了硬件/软件渲染、真实 Windows 测试媒体、系统通知和网易云部分操作。
QQ 音乐、汽水音乐、QQ 各窗口状态、Windows 10/不同实体硬件及多天运行仍需继续实测。
没有宣称所有电脑绝不卡顿。源码目录 docs 内提供完整报告、功能清单和测量口径。

可回退：从托盘退出此版，再运行保留的旧版 EXE。不要同时运行两个版本。
