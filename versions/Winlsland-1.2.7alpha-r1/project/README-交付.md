SDK：sdk；完整媒体手册：docs/媒体资源与皮肤扩展.md。

录制：verification/dynamic-media-real-window.mp4（宿主真实渲染帧采样）。
完整哈希：verification/delivery-hashes.json；基准校验与备份见报告。
