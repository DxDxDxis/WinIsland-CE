## 运行原理与范围

程序读取当前用户 Windows 通知中心中新到达的标准通知，解析标题和正文后交给 WPF 灵动岛窗口显示。默认采用历史基线，不补播启动前的旧消息。

单文件分发能够免去项目依赖安装，但不能代替目标电脑的操作系统、Windows 通知服务或 QQ 的提醒设置。QQ 只在应用内部显示消息、托盘闪烁或自绘弹窗时，不属于现有监听范围。音量／亮度等系统浮层也不等同于标准通知。

支持范围沿用原项目的 Windows 11 x64。未经其他系统实测，不能保证在精简／组件损坏的 Windows、不同内部通知数据库结构或其他 CPU／操作系统上正常使用；打包也无法消除这些系统条件。

设置自动保存在 `%LOCALAPPDATA%\WinIsland\settings.xml`。首次正常启动会登记当前用户自启动项；托盘“退出”会按原设计移除。社区版和原版共用单实例与设置，切换版本前先退出正在运行的版本。
