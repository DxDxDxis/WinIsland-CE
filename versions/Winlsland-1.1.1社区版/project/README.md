# WinIsland 1.1

桌面文件：`WinIsland-1.1.exe`。先退出正在运行的旧版，再双击新版。无需安装或管理员权限。旧版 `WinIsland.exe` 保留。

## 本次更新

- **内容自适应尺寸**：按标题和正文的实际排版宽度、高度展开。短通知更紧凑，长通知自动换行；浮窗最大宽度 560 个逻辑像素，高度限制在屏幕可用范围内。超出最大区域的长文本截断显示。
- **设置窗口**：右键托盘图标，“设置”位于“退出”上方。关闭设置窗口后继续在托盘运行，重复打开只显示同一个设置窗口。
- **灵动岛常驻**：默认开启。关闭后药丸平滑移出屏幕顶部，收到通知时滑入，通知结束后再次滑出。重新开启立即恢复常驻；正在显示的通知会正常显示完毕。
- **隐藏Windows自带通知**：默认开启。运行期间临时遮蔽系统通知横幅窗口，通知仍保存在 Windows 通知中心并由灵动岛显示。关闭开关或退出程序时解除遮蔽。此开关控制横幅显示，通知声音仍由 Windows 管理。
- **通知停驻时间**：默认 4 秒，从展开完成后开始计时。支持 0.1–3600 秒的小数值。修改时按新时长和当前通知已停留的时间立即重新计算；无效或空输入不会覆盖上次有效设置。
- 所有设置立即生效并自动保存，下次启动继续使用。

## 保留功能

启动时无主窗口或控制台，仅显示托盘图标和纯黑色药丸。药丸固定于主屏幕顶部中央、离顶部 8 个逻辑像素，默认 164 × 34；鼠标穿透，不可拖动。展开、收回和滑入滑出采用非线性阻尼曲线。连续通知按顺序显示，每条采用设置的停驻时间，最多保留最近 8 条待显示通知。

首次启动写入当前用户的开机登录启动项。右键托盘“退出”将结束主进程和通知恢复辅助进程、解除原生通知遮蔽、删除自启动项。手动再次打开会重新加入自启动。关机、注销和正常系统结束程序时保留自启动。锁屏或睡眠时隐藏内容，恢复后不补播历史通知。

## 通知范围与实现

监听当前用户 Windows 通知中心内新增的标准 toast 通知，每 650 毫秒以严格只读模式读取 Windows 通知数据库。不上传、记录通知正文。未进入 Windows 通知中心的应用内部消息、自绘弹窗，以及被系统或应用拦截的消息不在监听范围内。

原生通知隐藏通过窗口事件钩子识别 Windows 系统通知宿主的通知窗口，并临时遮蔽其绘制区域，不修改系统的通知开关、应用通知权限或数据库内容。恢复辅助进程通过父进程和输入管道监测主程序：主程序异常退出时，辅助进程恢复自己遮蔽的窗口后退出。因此开启此功能时，任务管理器中会有一个主进程和一个辅助进程。

通知数据库及系统通知窗口均属于 Windows 内部实现。本版本针对 Windows 11，以及中文、英文标准通知宿主标题进行适配；未来系统版本改变内部结构时可能需要更新。验证使用真实 Windows 通知检查接收通路，并使用独立的窗口夹具验证跨进程遮蔽、开关恢复、正常退出恢复及主进程异常退出恢复。

## 文件位置

- 设置：`%LOCALAPPDATA%\WinIsland\settings.xml`
- 自启动：`HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 下的 `WinIsland` 值。
- 错误诊断：`%LOCALAPPDATA%\WinIsland\diagnostics.log`，仅异常类别、错误码与时间，不包含通知内容。

移动 EXE 后重新运行一次，可以更新自启动路径。

## 构建与验证

使用 Windows 自带 .NET Framework 4.x / WPF，编译目标为 x64 GUI 程序，多尺寸图标和清单嵌入 EXE。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
Start-Process .\artifacts\WinIsland-1.1.exe -ArgumentList '--self-test', '.\artifacts\self-test.txt' -Wait
Start-Process .\artifacts\WinIsland-1.1.exe -ArgumentList '--preview', '.\artifacts\preview' -Wait
```

`--self-test` 检查解析、历史去重、设置默认值与保存、输入校验、排版尺寸、非线性曲线和只读数据库；`--preview` 检查动画、常驻滑动、当前通知计时调整及设置窗口，并导出 PNG。两者都不更改用户设置和自启动。`verify.ps1` 使用隔离设置文件进行完整集成测试；测试输出目录应是尚未使用的新目录。

正常使用直接运行 EXE，不需要任何参数。
