# 网易云最小化歌词接口核验

核验日期：2026-09-07（Asia/Shanghai）。本次通过 Python 标准库 HTTP 只读获取微软官方文档、LRCLIB 官方源码、Google 官方文档源码、网易云服务实际响应和社区接口实现；没有操控播放器、启动模拟播放器或修改产品代码。本文不保存完整歌词。

## 结论

1. **歌词正文与当前播放进度是两种数据。** LRCLIB 和网易云歌词服务按曲目元数据或歌曲 ID 返回整首歌词及歌词内部时间戳，没有返回本机网易云当前播放位置、暂停状态或当前歌词行的字段。它们可以绕开播放器窗口获取正文，但不能单独解决最小化后的播放位置缺失。
2. **SMTC 是已核实的 Windows 官方会话时间轴接口。** `Position` 是 `LastUpdatedTime` 时刻的位置，不是文档承诺自动递增的实时时钟；事件表示发布的时间轴属性改变，不保证逐秒触发。播放器未提供有效时间轴时，重复读取或改成事件订阅都不能凭空获得正确位置。[M1–M6]
3. **当前网易云歌词接口可用，但不是有官方稳定性承诺的公开 API。** 歌 ID `347230` 的普通接口与 v1 接口本次均为 HTTP 200、业务 `code=200`，均有 49 行 `lrc.lyric`。不能据此承诺所有歌曲、所有地区、未来版本或请求频率下均可用。[N1–N4]
4. **不能沿用旧版 LRCLIB 接口假设。** 当前官方 `main` 路由只有 `/api/get`、`/api/get/:track_id`、`/api/search` 等，没有 `/api/get-cached`；后者本次两次实测为 HTTP 404 空响应。`/api/get` 与 `/api/search` 本次可用。[L1–L7]

## Windows 官方时间轴的确切语义

| 接口／属性 | 官方文档明确的含义 | 对本项目的限制 |
| --- | --- | --- |
| `GlobalSystemMediaTransportControlsSession.GetTimelineProperties()` | 获取表示该会话时间轴状态的属性对象。 | 文档没有说此调用会主动查询播放器内部解码位置。[M1] |
| `TimelinePropertiesChanged` | 会话时间轴属性变化时发生。 | 不是固定周期定时器；未发布新的属性就不能假定会收到有效进度。[M2] |
| `TimelineProperties.LastUpdatedTime` | 时间轴属性最后更新的 UTC 时间。 | 是这份时间轴的更新时间，不是取值调用时间。[M3] |
| `TimelineProperties.Position` | “The playback position, current as of LastUpdatedTime.” | 需结合更新时刻理解；单独重复读取旧 Position 不意味着播放器停止播放。[M4] |
| `TimelineProperties` 类 | 包含 Position、StartTime、EndTime、MinSeekTime、MaxSeekTime 等。 | `EndTime` 是媒体结束时间戳，不能把无效的全零时间轴当成一首正常歌曲的完整时长。[M5] |
| `SystemMediaTransportControls.UpdateTimelineProperties()` | 用传入对象中的数值更新 SMTC 时间轴属性。 | 官方存在播放器侧的发布机制；消费方不能将未发布的数据当作已知。[M6] |

此组全局会话时间轴 API 最低为 **Windows 10 1809／10.0.17763.0**，`Windows.Foundation.UniversalApiContract v7.0`；文档列出的 App capability 是 `globalMediaControl`。[M5] 本次读取的是 Microsoft Learn `winrt-26100` 文档视图，不把网页的通用预发布提示解读为此 API 刚刚新增。

已知有效 `Position`、可信更新时间、播放状态、播放速率时，可以设计客户端位置外推，但那是**估算**；暂停、跳转、换曲、倍速改变后必须重新校准，文档不保证外推等于播放器内部位置。全零时间轴和冻结的当前歌词行不能支撑准确外推。仅有歌词行文字匹配时，同一句可能多次重复，而且一行持续数秒，无法推得唯一、精确的当前位置。

## LRCLIB：官方源码与当前服务响应

访问 [LRCLIB 文档页](https://lrclib.net/docs) 得到 HTTP 200，但本次直接获取的页面只是前端壳。接口事实以服务自身的官方代码和实测为依据，未引用第三方教程。官方仓库核验版本：`05ad8590f6fc4d47a2d74e70f4915273df20f63c`，提交时间 `2026-08-07T08:00:58Z`。[L1]

| 请求 | 当前实现／实测 | 能力边界 |
| --- | --- | --- |
| `/api/get` | 官方 `QueryParams` 要求非空 `track_name`、`artist_name`；`album_name` 和 `duration` 可选；传入 duration 时范围为 1–3600 秒。返回对象包括 `id`、歌曲信息、`duration`、`instrumental`、`plainLyrics`、`syncedLyrics`、`lyricsfile`。[L2] | `duration` 是曲目时长，不是本机已播放时间；普通歌词可能没有同步时间戳。 |
| `/api/get` 匹配 | 官方数据库查询要求规范化后的歌名和歌手匹配；若提供专辑则增加专辑约束，若提供时长则允许 ±2 秒；以 `tracks.id` 排序并 `LIMIT 1`。[L3] | 接口返回成功不表示已验证唯一录音版本。当前 SQL 实际排序按 ID，不应只看旁边“Prefer tracks with synced lyrics”的注释就声称优先同步歌词。 |
| `/api/search` | 官方参数为 `q`、`track_name`、`artist_name`、`album_name`；返回候选数组及歌词字段。[L4] | 调用方仍须检查歌手、专辑、版本、时长等；结果第一项不是官方承诺的正在播放曲目。 |
| `/api/get-cached` | 当前官方 router 没有此路由；duration=369 和 duration=367 两次真实请求均 HTTP 404、空体。[L5、L7] | 不能把当前 404 简单解释成“歌词未缓存”；不能将旧教程描述当成当前可调用能力。 |

本次实测均使用 `Get Lucky`／`Daft Punk`：

- [带专辑和 duration=369 的 `/api/get`](https://lrclib.net/api/get?track_name=Get%20Lucky&artist_name=Daft%20Punk&album_name=Random%20Access%20Memories&duration=369)：HTTP 200，ID `3606695`，返回 duration `367.0`，`plainLyrics` 132 行、`syncedLyrics` 114 行；符合 ±2 秒范围。
- [只含歌名和歌手的 `/api/get`](https://lrclib.net/api/get?track_name=Get%20Lucky&artist_name=Daft%20Punk)：HTTP 200，ID `986804`，返回 duration `248.0`。**相同歌名、歌手，不同请求约束会取得明显不同时长的录音。**
- [duration=0 的 `/api/get`](https://lrclib.net/api/get?track_name=Get%20Lucky&artist_name=Daft%20Punk&duration=0)：HTTP 400，`ValidationError`，消息 `duration: must be between 1 and 3600`。
- [歌名和歌手搜索](https://lrclib.net/api/search?track_name=Get%20Lucky&artist_name=Daft%20Punk)：HTTP 200，20 条候选；前两条返回 duration 370、368 秒，专辑名称不同。

上述请求不携带本地播放器会话标识，不读取窗口。由其请求参数和返回结构可确定：窗口可见性不是获取这些歌词正文的条件；但网络状态、服务数据覆盖及匹配质量仍影响结果。当前 `get` 官方实现查询数据库并有本地结果缓存，未出现旧文档中可能描述的“未命中就查询外部歌词源”的调用链。[L2–L5]

## 网易云：现存实现与服务实测

未核实到网易云为这两个地址发布的官方开放平台文档或稳定性承诺。**应将它们标为网易云服务的非公开接口，而不是网易云官方公开 API。** 直接访问 `music.163.com` 的响应是一手服务行为证据；社区模块只能证明社区当前如何调用，不能证明网易云的官方承诺。

社区 `neteasecloudmusicapienhanced/api-enhanced` 核验版本为 `d55d92cd0031d7c7746b7068faecd7ade1d354ac`，提交时间 `2026-09-04T12:01:15Z`。其中普通模块调用 `/api/song/lyric`，发送 `id`、`tv/lv/rv/kv=-1`、`_nmclfl=1`；新版模块调用 `/api/song/lyric/v1`，发送 `id`、`cp=false`、`tv/lv/rv/kv/yv/ytv/yrv=0`。[N1、N2]

实际 HTTP 验证使用 GET、`Referer: https://music.163.com/`、自描述 User-Agent，无播放器会话或登录 Cookie；歌曲 ID `347230`：

| 实际请求 | HTTP／业务码 | 格式与数量 |
| --- | --- | --- |
| [普通接口：lv/kv/tv=-1](https://music.163.com/api/song/lyric?id=347230&lv=-1&kv=-1&tv=-1) | 200／200 | `lrc.lyric` 为带 `[分钟:秒]` 时间戳正文，1241 字符、49 行；`klyric`、`tlyric` 为空。 |
| [v1：各版本参数=-1](https://music.163.com/api/song/lyric/v1?id=347230&lv=-1&kv=-1&tv=-1&rv=-1&yv=-1&ytv=-1&yrv=-1) | 200／200 | `lrc.lyric` 1911 字符、49 行；`romalrc.lyric` 1734 字符、38 行；`klyric`、`tlyric` 为空。 |
| [v1：社区模块的各版本参数=0、cp=false](https://music.163.com/api/song/lyric/v1?id=347230&cp=false&tv=0&lv=0&rv=0&kv=0&yv=0&ytv=0&yrv=0) | 200／200 | `lrc.lyric` 49 行、`romalrc.lyric` 38 行；本曲响应没有 `yrc`。 |

两类接口的本次顶层字段为歌词、歌词贡献者信息、状态标记与业务码，**没有本机当前 position、paused 或 currentLine**。歌词时间标签描述各歌词在录音内的位置；不能把它们当作本机已播放位置。

社区源码把新版模块描述为支持逐字歌词，但本次歌曲并未返回 `yrc`，因此不能声称 v1 对所有歌曲都能提供逐字歌词。普通版和 v1 的正文内容长度也可能不同；实现需按实际存在的字段解析，不应仅依据端点名称假定格式。

已知 `Binaryify/NeteaseCloudMusicApi` 原仓库当前 API 元数据显示 archived，最后推送时间为 `2024-02-28T02:47:42Z`，因此没有把旧仓库名称或第三方老教程作为“最新接口”证据。[N3]

## 最小化与 UI 冻结：证据不能越界

Google 官方 Chrome 88 定时器文档说明：隐藏通常包括窗口最小化；`requestAnimationFrame` 会等待页面重新可见；定时器限流取决于隐藏时间、声音与 WebRTC 等条件。尤其最近发声的页面满足较低限流条件，不能简单声称“音频播放中最小化必然冻结所有 JS 定时器”。该文章发布于 2021-01-18，更新于 2023-04-18，本次通过 Google 官方文档源码核验。[C1]

这能说明依赖 Chromium UI 更新的读取路径可能受可见性影响，但**不能单凭 Chrome 文档认定网易云 3.1.39.205426 内部具体使用何种定时器、是否人为暂停歌词渲染，或证明其冻结原因**。Chromium UI 可访问性快照不是文档承诺独立于渲染更新的播放进度接口。

主任务提供的真机观察为：网易云 `3.1.39.205426` 的 SMTC 元数据和播放状态正常，但原始时间轴全部为零；主窗口可见时 MSAA/IAccessible2 的 `line current` 更新，最小化后冻结。**这是主任务的特定版本现场观察，不是本研究再次运行播放器所得，也不是全部网易云版本的官方保证。**

对这组现场条件，已核验的公共歌词服务可以提供整首正文；已核验的 Windows 官方接口暂时没有从该播放器得到有效位置。**在本次查阅的微软文档、网易云服务响应及现存接口实现范围内，没有找到受支持且可验证、能让第三方独立于窗口可见性读取网易云本地实时播放进度的接口。** 这是本次核验范围内的结论，不是证明所有版本或所有内部接口均不存在。

保持同步还需要一个可独立于 UI 更新的可信播放位置来源。若实现仅从最后观察到的歌词行开始计时，必须标明估算，并处理暂停、跳转、换曲及重复歌词；不能将其验证为“真实位置读取”。保留最后核验的歌词并明确显示为静态回退，能诚实表达当前能力；不得将其称为最小化后的实时同步。
