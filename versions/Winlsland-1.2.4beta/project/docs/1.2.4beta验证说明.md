# 1.2.4beta 设置与音乐修复交付说明

## 成品与运行

- 成品：`release/1.2.4beta-设置修复完成版/WinIsland-1.2.4beta.exe`。
- 版本保持 **1.2.4beta**；原版及之前的中间成品保留，未覆盖正在运行的程序。
- 原生 C++20，Win32 设置窗口；灵动岛使用 D3D11 / Direct2D / DirectComposition，保留 Direct2D 软件回退。
- Windows 10 1809 或更新版本，x64。MSVC 运行库使用 `/MT` 静态链接，图标与清单内嵌。PE 导入检查仅有 Windows 系统库；无需安装 Python、Qt、.NET 或浏览器运行时。
- 本次成品 890,368 字节；此前中间成品 880,128 字节。本次为修复增加约 10 KB，未声称体积降低。
- 构建：`./build.ps1 -BuildTools E:\WinIslandBuildTools -OutputDirectory ./tools/settings-build -IncludeTests`。编译环境需要 MSVC x64 和 Windows SDK；成品运行不需要开发工具。
- 正常运行使用原配置目录和 XML，设置自动保存。测试使用 `--verify` 的独立配置，未改写用户的正式设置。

## 设置页：原因、修复和边界

旧设计将整个长表放在顶层窗口内，父背景的离屏位图与子 HWND 的绘制分别提交。控件移动、背景重画及动态文本更新没有共同的提交边界；仅在滚动结束后截屏，不足以证明中途没有闪烁。此前还存在滚动重建字体和逐控件立即重画的问题。

本次代码检查另确认：关闭的 COMBOBOX 的实际窗口高度仅为选中项高度，但布局每次滚动都重新传入下拉列表高度，触发不必要的原生尺寸处理。固定标题、导航和整个视口也被反复定位。它们是可以实际移除的多余工作；不能据此断言它们解释了其他电脑的全部卡顿。

修复方案：

1. 固定顶部导航：**界面通知 / 音乐歌词 / 实时信息 / 运行诊断**，保留全部设置 ID、原有默认值与配置行为。
2. 单一子窗口滚动视口，使用 `WS_EX_COMPOSITED` 统一缓冲其原生子控件，配合 `WS_CLIPCHILDREN / WS_CLIPSIBLINGS`。设置页不使用分层透明窗口。灵动岛原有透明合成、鼠标穿透与帧率策略未关闭或降低。
3. 布局批量使用 `DeferWindowPos`，禁用旧像素拷贝；仅在几何真正改变时定位，滚动只移动控件，不反复调整下拉框尺寸。固定导航不随内容滚动。
4. 移除重复的全窗口离屏位图，视口依据无效矩形绘制。静态文字完整清底再绘制，文字变化通知所属视口更新对应区域；清空和缩短文字都覆盖旧区域。
5. 控件创建一次，各分类显隐复用；字体只在 DPI 改变时更新，所有隐藏控件也先切换新字体再释放旧字体。
6. 统一卡片、圆角输入框、按钮与下拉框闭合态绘制。下拉框仍使用原生列表、选项、键盘和可访问性行为；保留键盘焦点提示。
7. 普通内容、输入框及闭合下拉框的滚轮统一归主视口；展开下拉框才滚选项，支持小滚轮增量。Tab 自动将焦点控件滚入可见区域。
8. 设置页不增加装饰动画、模糊或轮询重绘，因此不需要用降低帧率来稳定显示。UI 线程只做绘制和布局，网络、歌词、音频、日志仍在原后台模块。

关于测试证据：跨进程自动化必须用 `WM_SETTEXT` 更新控件。早期脚本使用跨进程 `SetWindowTextW`，绕过预期控件消息，产生了不可信的残影失败；最终已改为真实消息路径。这些早期脚本失败不计为已确认产品根因。图像比较排除了 Windows 窗口圆角的屏幕背景像素和滚动条悬停动画，比较实际设置内容。

## 短时性能对照

同机、同脚本各约 90 秒，包含音乐、歌词测量、消息与反复展开/收起，后 60 秒持续运行。该脚本主要测灵动岛，不是设置页滚动专用基准。

| 指标 | 之前成品 | 此次成品 |
|---|---:|---:|
| 启动到 ready | 632 ms | 665 ms |
| 平均绘制耗时 | 0.685 ms | 0.698 ms |
| 最大绘制耗时 | 11.128 ms | 10.924 ms |
| 平均帧间隔 | 16.683 ms | 16.686 ms |
| 帧间隔 P99 桶 | 22 ms | 22 ms |
| 最大帧间隔 | 30.713 ms | 34.175 ms |
| 工作集 | 60.63 MB | 60.49 MB |
| 私有内存 | 43.17 MB | 42.92 MB |
| 全机平均 CPU（20 逻辑核） | 约 0.592% | 约 0.599% |

此次没有测出整体动画帧率的显著改善，也仍有超过一帧的间隔峰值；不宣称“彻底不卡顿”。设置页减少了重复原生 resize 和旧像素拷贝，其修复证据是交互及像素回归，不是把短时 CPU 波动归功于优化。GPU 占用没有直接采样。证据：`tests/bench-before-final/metrics/latest.csv`、`tests/bench-settings-final/metrics/latest.csv`。最终 EXE 的自检也通过：`tests/selftest-delivered.txt`。

## 音乐竖条与已有功能

- 12 根真实音频竖条保留，每条 **2.1 DIP 宽**、最大 **18 DIP 高**，正常间距 **2.4 DIP**，整体区域 **51.6 DIP** 宽。
- 右边缘固定在距音乐外壳右侧约 **15.95 DIP**，增加范围向左；空间不足时压缩间距，必要时优先隐藏非必要指标的绘制，保护歌曲信息和控制。
- 普通音乐外壳约 **393.69×41.37 DIP**，没有为竖条扩大；待机 **180.4×29.92 DIP** 不变。展开状态的控件命中区域随音乐尺寸统一缩放。
- 成品测试通过真实 PCM 音量变化、静音回落、SMTC 暂停/继续/切歌、歌词同步与切歌清理、FPS/Ping 同时开启不重叠、12 条消息排队，以及 100/125/150/200% 应用缩放截图。
- 仍为真实进程音频回环；不支持进程回环的 Windows 版本可用音频会话真实峰值回退。没有随机条动画。
- 待机 600 ms 长按轻亮反馈、取消恢复、原有 5 秒控制面板收回、10 秒音乐停止收回和透明命中区域沿用。

## 歌曲、歌词和实时指标

| 功能 | 实现 / 默认 / 限制 |
|---|---|
| 歌曲信息 | `src/media.cpp` 后台 SMTC，默认“仅 SMTC”。“自动”才允许同歌标题补齐或窗口标题回退；“仅窗口标题”不偷偷切回 SMTC |
| 歌词 | `src/music_sources.cpp` 后台 HTTPS WinHTTP，默认自动 API→缓存；可选仅 API 或关闭。默认 `https://lrclib.net`，可换兼容 LRCLIB 协议的 HTTPS 根地址，不是任意歌词网址 |
| 匹配/缓存 | 标题、歌手及录音时长验证，请求代次防旧响应覆盖；错误、空歌词、歧义不显示上一首。LRC offset、多时间戳和同时间翻译行通过 |
| 网络失败 | 超时、有限重试、429、5xx、格式错误、缓存降级及严格 API 模式已测；此前同歌 60 秒后恢复也已测 |
| FPS | `src/telemetry.cpp`，默认关闭。ETW DXGI 实际提交帧率；不等于屏幕刷新率或最终扫描帧率。无权限、不支持接口、无前台帧显示 `--`；不强制提权 |
| Ping | 同模块，默认关闭。IPv4/IPv6 异步 ICMP，每 3 秒采样、650 ms 超时、最多两次。默认实际路由网关，可设置 IP 字面量；不把 HTTP 或 DNS 耗时冒充 Ping |
| Ping 空值 | 超时、无路由、不可达等清旧值并显示 `--`；实际成功小于 1 ms 显示 `<1 ms`，不伪造 0 ms。防火墙禁 ICMP 时无法给出真实延迟 |

此前真实 FPS 生产程序对照约 129–138 FPS，通过切换/最小化/恢复/退出和停采检查：`tests/fps-final/result.json`。本机 IPv4/IPv6 回环、真实有线网关、不可达地址→恢复已测；无线、物理断网未测。

平台能力不能从测试夹具推定：

- **网易云音乐**：本机真实读取歌曲/封面、歌词 API 获取成功，SMTC 报告上一首/播放暂停/下一首能力；但当前播放器未上报 timeline，无法真实同步歌词。不能把“取到歌词”写成“实时歌词已可用”。
- **QQ 音乐、汽水音乐**：标题格式和能力处理有测试，未完成真实平台播放及控制验证。功能依赖对应版本实际 SMTC 上报。
- 收藏和播放模式没有可靠状态或操作能力时不显示虚假按钮。
- QQ 前后台、托盘、重启等真实消息场景本次未重新实测；消息队列测试不是 QQ 全场景已解决的证明。

## 修改位置

- `src/app.cpp`：设置窗口结构、单一视口、分类布局、完整文字绘制、原生控件外观、滚轮/焦点、去重复尺寸处理、诊断几何数据。
- `src/render.cpp`、`src/render.h`：竖条左扩布局及验证用几何数据，保留音乐控制/消息布局。
- 本版本此前工作还包括 `src/media.cpp`、`src/music_sources.cpp`、`src/telemetry.cpp`、`src/audio.cpp`、相关头文件、版本资源及 `build.ps1`。
- `tests/verify-settings-categories.py`：设置页成品回归；`tests/verify-124.py`：适配子视口并验证竖条位置/大小和音乐集成行为。

日志默认位于 EXE 同级的 **daxian日志** 文件夹；目录不可写则保存到用户“文档/daxian日志”，设置页显示实际路径。日志不记录聊天正文或账号凭据。
