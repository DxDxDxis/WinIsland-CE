# 1.2.4beta 歌词多源修复

## 成品

`release/1.2.4beta-歌词多源修复版/WinIsland-1.2.4beta.exe`

原生 C++20 / C++/WinRT，版本仍为 1.2.4beta。成品 983,040 字节，MSVC `/MT`，复用 Windows WinHTTP 和 Windows.Data.Json；不增加第三方运行库。保留此前设置残影、竖条、消息与命中区域的修复。旧成品未覆盖。

构建：`./build.ps1 -BuildTools E:\WinIslandBuildTools -OutputDirectory ./tools/lyrics-final-build -IncludeTests`。

## 已确认原因

1. 原代码在线来源只有 LRCLIB，缓存放在网络失败之后，没有网易云搜索和普通/新版歌词接口。
2. 中间实现使用未经验证的网易云搜索路径，未区分数据源模式；网易云原始 JSON 不能被 LRCLIB 缓存读取器识别。现使用实测的 `/api/search/get?s=...&type=1&limit=30&offset=0`，统一保存带候选元数据、来源和格式的缓存。
3. 中间 YRC 处理只清除行首逐字标记，且时间转换不安全；现在校验全部数字标记、移除每个逐字标签，并保留毫秒级行时间。LRC 为空时继续检查 YRC。
4. 切歌取消请求曾被误判为服务网络故障，给下一首错误施加退避；现取消只作废旧代次，不能标记服务不可用。
5. 本机网易云实际仅上报歌名、歌手，专辑、时长和时间轴为空。仅凭该数据不能同步。原严格匹配直接拒绝；现仅在搜索得到一个歌名、全部歌手、版本标记完全一致且曲库元数据完整的候选时使用其歌词。多个录音候选仍拒绝。日志明确记录 `player_album_duration_unavailable`，不补造 SMTC 进度。
6. 播放器退出收回动画结束后补清理场景歌词，避免逻辑上残留旧文本。

## 查询顺序与设置

本地手动导入 LRC 为显式覆盖，继续优先。自动模式：

**已匹配缓存 → LRCLIB 精确 `/api/get` → 网易云搜索确定 ID → `/api/song/lyric` → `/api/song/lyric/v1` → LRCLIB `/api/search`**。

任一同步结果成功即停止。纯文本先保留，继续寻找同步结果，最终无同步结果才显示纯文本预览，标记“文本歌词”。有时间戳但播放器无时间轴时显示静态“未同步”预览，不轮播、不从请求时刻计时。

歌曲信息默认“自动（SMTC → 窗口标题）”，SMTC 在音乐后台线程读取，歌词独立线程查询；歌词失败不丢弃 SMTC 歌曲、封面或控制会话。现有用户明确选择“仅 SMTC”或“仅窗口标题”的配置继续保留。

歌词来源：

| 存储值 | 设置项 | 行为 |
|---|---|---|
| 0 | 自动（缓存优先，多源顺序查询） | 默认，完整顺序 |
| 1 | 仅 LRCLIB（在线） | 精确→搜索，不使用网易云；保留旧在线模式的“不读 API 缓存”语义 |
| 2 | 关闭歌词 | 不读/请求/显示歌词 |
| 3 | 仅网易云歌词 | 匹配的网易云缓存→搜索 ID→普通→新版 |
| 4 | 仅 LRCLIB 搜索 | 对应来源缓存→候选搜索 |

配置立即保存到原 XML，旧键及值兼容。LRCLIB 根地址仍可设置为兼容协议的 HTTPS 服务；网易云为 `https://music.163.com`。歌曲识别与歌词来源分别显示。手动导入/清除和日志导出入口保留。

## 匹配与网络约束

- 清理首尾空白、全角 ASCII、大小写，歌名完整匹配；分隔的全部歌手按集合比较，不只取第一位。
- 有实际时长时，候选必须有有效时长且相差不超过 3 秒；缺少候选时长不能放行。有专辑时优先同专辑；同录音时长可以接受普通合辑，但现场、翻唱、加速、降速、混音、伴奏、重制、不插电、小样等版本标记不得冲突。
- 网易云选取唯一匹配 ID，使用 64 位保存；不采用第一项。同条件多个 ID仍拒绝。
- 没有专辑与时长时，唯一精确候选不能证明未标注的录音差异完全不存在；此时只有歌曲名/歌手/版本和搜索唯一性证据，诊断明确注明。无法唯一匹配则暂无歌词。
- 各请求在后台，分阶段 1.8 秒超时、响应读取 4 秒上限、1 MB 响应上限，每端点至多两次；HTTPS 证书由系统校验，禁自动重定向和 cookies，不使用登录凭据。
- HTTP/API 429、网络错误、5xx等对服务退避；429 数字 Retry-After 限定 30–300 秒，其余默认 60 秒。服务退避跨歌曲生效；LRCLIB 故障时跳过重复候选搜索，独立网易云可继续。每首最多两轮延后重试。
- 切歌代次校验贯穿请求/解析/提交。正在等待的旧网络调用可能占用后台到超时，但不能覆盖新歌，也不阻塞 UI。
- 网易云非正式稳定 API，可能因地区、版权、限流、登录要求或服务变更失效；新版端点不保证提供 YRC。不会绕过服务权限。

## 修改文件与诊断

- `src/music_sources.cpp`：统一 HTTP、固定回退、服务退避、严格候选选择、LRC/YRC/纯文本、统一缓存、实际来源与失败原因日志、公网验证命令。
- `src/core.h`、`src/core.cpp`：默认歌曲策略、兼容新增来源值、歌词格式/来源/文本预览数据。
- `src/app.cpp`：来源设置、无时间轴标识、退出清理、诊断状态字段；SMTC 仍沿用 `src/media.cpp` 后台工作机制。
- `src/tests.cpp`、`tests/media-fixture.cpp`、`tests/verify-lyric-providers.py`、`tests/verify-live-lyrics.py`、`tests/song-metadata-probe.cpp`：测试。

在设置点击“启动信息监测”，问题发生后导出。EXE 同级 `daxian日志` 保存报告；不可写则回退文档目录。日志记录播放器平台、歌曲请求代次、元数据匹配/歧义、实际来源、HTTP/API/WinHTTP状态、回退理由、格式和 timeline 有效性；不写聊天、账号凭据或完整歌词正文。
