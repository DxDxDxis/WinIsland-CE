# 时间显示 1.0.0 — daxian

**当前 no-motion/c2 API 下始终安全隐藏，不会显示时钟。此包不是已完成可见待机时钟功能的版本。**

原因：公开 C ABI 没有权威待机/展开/设置窗口/图层占用状态；music.changed 和 notice.received 只说明内容到来，不能说明结束。getSetting 只能读取本插件设置。WI_LAYER 会增加主程序 footer 高度，没有固定尺寸待机文本目标。为遵守“不改主程序、不改尺寸、不覆盖其他内容”，本插件不注册图层、不猜测待机。

安装：设置 → 其他设置 → 插件管理 → 添加模组，选择 time-display.wimod，再在插件模组管理中启用。用户只需这个包，不要手动复制 DLL。

本副本新增“显示时间”设置：在“插件模组管理”选中时间显示 → 插件设置 → 显示时间，输入 `true` 开启或 `false` 关闭，点击现有“保存设置”。也接受 `1` / `0`。当前宿主只有文本设置，没有布尔开关控件；不往主程序“实时信息”页面添加控件。

设置 key 为 `time-display-enabled`（当前宿主不接受 WI_SETTING key 中的句点）。首次默认 true，关闭后立即撤销时钟检查定时器并清空缓存；重新启用或重载由宿主恢复已保存值。无效值或读取失败按关闭处理并记录原因。**true 只启用时间检查，当前仍不能显示时间**。

设置与事件在 onEnable 注册，因为当前宿主禁用时撤销全部资源、重新启用未必调用 onLoad。禁用后插件设置中不再有此设置资源，重启后不会出现重复项。

启用后记录能力限制，使用宿主管理的两个事件监听和一个 30 秒定时器读取 Windows 本地时间；按 `2026.9.21 09:05` 格式缓存，不显示秒、不每分钟写日志。时区及系统时间更改在下次检查生效。无独立窗口、进程或线程。

禁用会清理自己的所有资源；卸载退出 DLL 运行态，保留包和日志。要移除安装文件，请在插件卸载后手动移走包，不要删除其他插件。

正常日志：%LOCALAPPDATA%\WinIsland\mods\time-display\mod.log。诊断测试使用独立测试目录内的 mods\time-display\mod.log。

显示功能受宿主 API 限制。需要宿主以后提供完整状态及不增高的文本区域，并编写针对该真实接口的适配才能显示；当前不会自动切换到任何假设的未来接口。可见显示、视觉 DPI 和自动回到待机显示均未实现。
