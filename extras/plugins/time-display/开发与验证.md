## 插件代码和资源

- src/time-display.cpp：导出 WinIsland_ModAbi 和 WinIsland_CreateMod，所有生命周期通过 C 函数表调用。入口校验 size、version 和必要函数指针；分配/释放在同一个 DLL 内，/MT 静态 CRT。无 STL 对象跨边界，无独立进程、线程或 UI 窗口。
- onLoad 只记初始化日志；onEnable 注册 WI_EVENT music.changed、WI_EVENT notice.received，以及 WI_TIMER clock-check（30000ms，满足 SDK >=100ms）。
- 每 30 秒 GetLocalTime 读取 Windows 当前本地时间，用 SystemTimeToFileTime 作有效性校验；缓存格式为年.月.日 HH:MM。没有秒，月份/日期不补零，小时时分补零。检查失败清空缓存，错误只在状态变化时记录。
- 无法确认待机时永远不注册 WI_LAYER。因此缓存虽更新，但没有可见时间文字，也不绘制尺寸或 DPI 相关几何；这不是完整显示功能。
- 使用宿主日志，不在每次时钟检查写日志。同类音乐/通知原因重复到来不重复写说明。
- 记录三个句柄；禁用、卸载时移除自身资源并清零。兼容宿主先 revoke 再 onDisable 的顺序。重复启用不重复注册；部分注册失败撤销已注册项。
