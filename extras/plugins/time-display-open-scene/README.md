# 时间显示 1.1.0 — 居中修复与自定义颜色

在 WinIsland 内显示 Windows 本地时间，例如 `2026.9.14 17:14`。只包含年、月、日、时、分，不显示秒。

## 显示与位置

- 保持版本 `1.1.0`、作者 `daxian`、ID `time-display`。
- 默认 15 DIP、700 字重；岛过窄时适当缩小以保留完整日期，不扩大岛。
- 修正旧版将 `WI_ALIGN=1` 误认为居中的问题：DirectWrite 中 `1` 是右对齐，`2` 是居中。
- 使用 Microsoft YaHei UI 的真实文字宽度，整组文字按父节点宽高水平、垂直居中。分段颜色不会改变位置。
- 延续现有音乐、播放、歌词、通知隐藏条件。设置窗口、普通窗口和展开状态不触发隐藏。
- 日期分隔符跟随前一字段的颜色；冒号跟随小时颜色。

## 插件设置

位置：插件管理 → 时间显示 → 插件设置。选择设置项、编辑值并保存，约 1 秒内生效；设置由宿主持久化。

| 设置 | 用法 |
| --- | --- |
| 显示时间 | `1` 开启、`0` 关闭；兼容旧 `true/false` 配置 |
| 颜色模式 | `统一颜色`、`分别设置`、`自定义循环`、`彩虹循环` |
| 统一颜色 | 全部文字使用同一颜色，例如 `#FFFFFF` |
| 年／月／日／时／分颜色 | 在“分别设置”模式中分别生效 |
| 循环颜色 | 在“自定义循环”模式中使用 2–16 个颜色，例如 `#FF0000,#00FF00,#0000FF` |
| 循环一轮时长（秒） | 1–120，默认 6；这是颜色动画时长，不是时间显示字段 |

颜色值采用 `#RRGGBB`，大小写均可；使用宿主现有文本设置框输入。自定义循环按输入顺序平滑过渡，最后一种颜色过渡回第一种；彩虹循环自动遍历色相，不需要填写列表。两种循环均让整行文字同步变化。

无效颜色保留本次运行中上一次有效值并记录日志；重新加载时无效值采用默认颜色。默认模式为统一颜色，默认值 `#B8C2D1`，保留原有 90% 文字透明度。

## 运行、安装与构建

- 宿主管理的 100 ms 定时器检查时间和颜色；设置每秒读取一次。仅在文字、布局、显隐或颜色变化时提交。
- 隐藏期间停止颜色提交，恢复后读取当前时间；宿主开启减少动态效果时循环颜色保持静态。
- 不创建独立窗口或线程；不接收、不阻挡鼠标键盘输入。禁用后撤销自己的全部节点、设置资源、定时器和事件。
- 需要支持 `winisland.scene` ABI 1 和 `winisland.settings` ABI 1 的 x64 WinIsland。
- 使用插件管理器导入本目录 `time-display.wimod` 并启用。当前宿主可能拒绝相同 ID 的重复导入；更新前保留旧包和设置，按宿主支持的卸载／替换流程操作。
- 构建：在本目录执行 `./build.ps1`；验证：`./tests/run.ps1`。依赖 MSVC x64、Python（打包）和 Windows 系统 DirectWrite，用户运行插件不需要 Python。
