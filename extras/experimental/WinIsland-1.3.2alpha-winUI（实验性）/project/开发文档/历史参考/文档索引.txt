版本区别

| 项目 | 最新 1.3.0 | 当前 1.3.1alpha |
|---|---|---|
| 工程目录 | 1.3.0-path-state-fix | 1.3.1alpha |
| 产品构建 | 1.3.0-path-state-fix-20260916 | 1.3.1alpha-settings-adjust-20260917 |
| 生命周期 ABI / 清单 API | 0x00010002 / 1 | 相同 |
| scene / settings / media 扩展版本 | 均为 1 | 相同，三个 SDK 头文件逐字一致 |
| 动态媒体接口 | 图片、GIF、H.264 已实现 | 继承，没有新增网页接口 |
| 音乐/消息呈现开关、文件中转 | 未提供该版新增功能 | 宿主功能，未导出为插件 SDK |
| 降低动画 | 原系统策略；不是可保存的手动开关 | 手动字段 reduceMotion，默认关闭并保存 |
| 插件管理覆盖范围 | 内容工作区 | 完整设置客户端区域 |

根目录 1.3.0 是较早的 community-settings 构建，不能与 1.3.0-path-state-fix 混为同一成品。当前源码为 source/src 和 settings-electron/src；sdk 是发布头文件。子目录中的旧示例自带源码/SDK是历史样本，不是当前宿主实现。

旧验收报告保留发生时的结论。带“AI提示词”“方案”的文件是需求/设计历史，不是已实现能力清单。旧快照与旧报告中的“不曾修改原目录”描述当时状态；2026-09-17 本次经用户要求同步更新了最新 1.3.0 的文档，未修改其源码、SDK 头文件或 EXE。
